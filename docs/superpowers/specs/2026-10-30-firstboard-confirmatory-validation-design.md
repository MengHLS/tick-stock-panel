# 首板因子确认性研究协议

日期：2026-10-30

## 1. 目的

把已有的探索性首板因子发现收敛为一个可复验、可证伪的研究协议，回答：

> 在首板事件样本中，T-1 或 T 日收盘可观察的布林带宽高位，是否能在真正未参与本轮观察的后续样本中，持续提高 20 日内最高收益达到 20% 的概率？

本协议不设计交易策略，也不把分类能力直接解释为可实现收益。

## 2. 当前证据等级

已有 2025-11-12 ～ 2026-09-23 验证结果只能标记为“已观察的回顾性验证”，不能称为独立确认，因为规则和验证区间都在本轮研究中被查看过。

可用于下一阶段确认的主假设在查看前瞻样本结果前冻结：

- 样本：平台口径首板事件，`consecutive_limit_ups == 1`；
- 主特征时点：T-1 收盘；
- 主因子：布林带宽；
- 主阈值：`0.41986322631304357`，即探索阶段 T-1 高位规则的原始阈值；
- 主标签：`mfe_20d >= 0.20`；
- 收益基准：T+1 复权开盘；
- 主规则不得因前瞻结果重新选因子、方向或阈值。

T 日收盘布林带宽阈值 `0.4548727152548999` 保留为次要假设，用于比较“多等一个交易日”是否值得。两条规则不得合并成一个事后最优分类器。

## 3. 目标、非目标与反目标

### 3.1 目标

- 用固定阈值和固定时间边界复验主假设。
- 同时报告命中率、提升、5/10/20 日最高收益、期末收益和最大不利波动。
- 以事件交易日为重采样单位，处理同日事件和重叠收益窗口的相关性。
- 检查年度、阈值邻域和同族波动因子的稳定性。
- 在数据版本、代码版本和规则完全固定后保存研究快照。

### 3.2 非目标

- 不自动生成交易策略、买卖点、仓位或止损规则。
- 不根据未来数据重新设定阈值。
- 不把最高收益当成可兑现收益。
- 不补齐未认证的历史 ST、板块涨跌幅制度或完整交易日历来源。
- 不把同族因子的多个高分结果当作多条独立证据。

### 3.3 反目标

- 在前瞻样本结果出来后再调整主阈值。
- 因某一年、某一市场状态或某个持有窗口更好看而替换主假设。
- 将 5/10/20 日重叠窗口视为独立样本。
- 用逐事件 Wilson 区间代替交易日聚类不确定性。
- 只报告最高收益而隐藏期末收益和最大不利波动。

## 4. 候选因子准入

确认性发现只允许平台内置、DSL、无量纲、稳定因子：

- `kind` 必须是 `base` 或 `virtual`；
- 不得是自定义因子、复合因子或 Python 表达式因子；
- `scale_free` 必须为真；
- `stability` 必须为 `stable`；
- 财务、规模、当前股本派生和扩展表因子不进入；
- `vwap_bias` 不进入，因为当前实现将复权收盘价与未复权成交均价混用；
- 未知因子默认拒绝。

这说明的是“候选准入 fail-closed”，不是对所有内置因子完成了形式化时点证明。主假设仍需人工审计其实际公式和依赖链。

## 5. 时间与数据契约

### 5.1 预注册时间边界

- 探索来源记录：`20261029T165702Z-36ad4a4861`；
- 来源算法版本：`firstboard-discovery-v2`；
- 口径修复复算记录：`20261029T172452Z-e5bf104ed3`，算法版本 `firstboard-discovery-v3`；
- v3 复算在相同 generation、固定训练截止和候选准入下得到与探索记录相同的两条布林规则及验证指标；
- 固定训练截止：`2025-11-11`；
- 已观察回顾验证：`2025-11-12` ～ `2026-09-23`；
- 前瞻锁定样本起点：事件日 `>= 2026-10-01`；
- 重跑时必须显式传入固定训练截止，禁止自动移动 70/30 边界。

2026-09-24 ～ 2026-09-30 的事件仅作为隔离带，不进入前瞻主结论，避免在查看部分短窗口结果后产生边界选择争议。

### 5.2 交易日

T+1 和后续 N 日窗口必须基于全市场 enriched 分区日期，不得从单只股票或当前加载面板的日期并集推导。

若某事件日后的首个全市场交易日没有该股票行情，事件必须标记为 `entry_unavailable`，不得顺延到该股票下一条可用日 K。

当前仍有一个残余风险：如果整个市场某交易日分区都缺失，本地分区轴本身无法证明那天的存在。该风险必须在最终报告中保留，除非接入覆盖目标历史区间的权威交易日历。

### 5.3 价格

- 特征和收益统一使用 enriched 前复权价格；
- 判断 T+1 开盘涨停使用原始价与涨停判定价；
- 不允许在同一公式中混用复权价与未复权成交均价；
- 价格尺度异常、T+1 无法成交和收益窗口不完整的事件必须显式排除。

## 6. 统计口径

### 6.1 主指标

```text
base_rate = P(strong | validation)
hit_rate = P(strong | validation, rule_hit)
lift = hit_rate / base_rate
rate_difference = hit_rate - base_rate
```

主结论要求同时满足：

- 命中事件数 `>= 300`；
- 命中的事件交易日数 `>= 60`；
- `lift >= 1.15`；
- 按事件交易日聚类的 95% bootstrap 区间下界 `> 1.00`；
- 年度方向不反转；允许样本较少年度单独标注，但不删除。

以上是分类门槛，不是盈利门槛。

### 6.2 收益与风险

同时报告命中样本的 5/10/20 日：

- `mean_mfe`：最高收益均值；
- `mean_close_return`：期末收益均值；
- `mean_mae`：最大不利波动均值；
- 三项相对全体验证样本的差值；
- 20 日期末收益和最大不利波动的交易日聚类 95% 区间。

经济可用性另设门槛：

- 20 日期末收益的 95% 区间下界必须 `> 0`；
- 最大不利波动不得比基准恶化到无法由风险规则解释的程度；
- 只有分类门槛和经济门槛都通过，才进入策略阶段。

### 6.3 多重比较

- 主假设只检验一次；
- 同年、阈值邻域、同族因子和 5/10 日窗口均为描述性辅助分析；
- 辅助分析不得用于重选主规则；
- 同族布林、ATR、年化波动和振幅趋势结果必须合并解释为“波动率高位”这一共同主题，不累计为独立证据。

## 7. 前瞻锁定流程

1. 固定本协议、主阈值和训练截止。
2. 使用修复后的 v3 发现服务重新生成研究快照。
3. 在事件日 `>= 2026-10-01` 且 20 日标签成熟的样本上做一次主分析。
4. 主分析前不查看命中率的中间结果；可以查看数据覆盖、标签完成情况和样本量。
5. 达到至少 300 条命中事件和 60 个事件交易日后，只执行一次主检验。
6. 无论结果正负，都保存报告、代码版本、数据 generation 和事件明细。

如果最终样本不足，应标记 `insufficient_lockbox_sample`，不能降低门槛或延长到出现显著结果为止。

## 8. 代码与验证边界

- `firstboard-discovery-v3` 增加候选准入、全市场分区交易日和可选预注册训练截止；
- 历史 run 的 `report.json` 和 `events.parquet` 继续只读兼容；
- 不修改核心因子公式，只为确认性发现排除未认证口径；
- 定向测试覆盖：未来自定义因子拒绝、价格混合因子拒绝、原始尺度因子拒绝、缺失全市场交易日不被顺延、固定训练截止可复现；
- 确认性脚本只读取已保存事件，不重新选阈值。

## 9. 当前决策

1. 布林带宽高位可作为“首板强度分类因子候选”继续确认。
2. 现有证据不足以支持交易策略。
3. 下一项正式动作是前瞻锁定验证，而不是参数搜索或策略回测。
4. 只有分类和经济两项门槛都通过，才另行设计退出、仓位和成本模型。
