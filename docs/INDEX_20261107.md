```python
import os,hashlib,time
def tup(p):
    b=open(p,'rb').read()
    return len(b), b.count(b'\n'), hashlib.sha256(b).hexdigest(), time.strftime('%Y-%m-%d %H:%M:%S',time.localtime(os.path.getmtime(p)))
for root,d,fs in os.walk('docs'):
    for f in fs:
        p=os.path.join(root,f); s=tup(p)
        print(p.replace('\\','/'), s[0], s[1], s[2][:16], s[3])
```

**口径**：字节 = 文件二进制长度；行数 = **LF 计数，末行无换行时 +1**（末行有换行时与 `wc -l` 相同）；sha256 = **全文 raw 字节**；mtime = 本地时间 Asia/Shanghai；sha 一律由我本机现算，**未抄任何自述**；「相符」= 自报值与实测值逐位相同。
