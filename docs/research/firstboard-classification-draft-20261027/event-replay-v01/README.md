# 四股逐事件回放 v0.1：交付与复核入口

状态：方法验证材料；新候选分类与因子仍待量化验证员独立验收。没有策略成交回测，没有正式效果结论。四股已被挑选并观察，均为开发样本。

## 事件集合与规则

本批固定为原长图窗口2025-10-13~2026-10-23内27个平台口径首板，去重键(symbol,date)：23个早于原目标日的事件，另含原目标日4例。股票000810、002687、600785、002354。不是工程师长历史63事件集合，也不是生产内核61事件测试集合。

432条分类记录 = 27个事件 × 16套候选规则，不是432个独立样本。16套组合是以下笛卡尔积：

- P取法：A排除首次下降日high / B包含。
- 回调阈值q：3% / 5%。
- 新峰值条件G：不要求 / 严格要求P超过锚点high。
- 锚点政策R：仅最近 / 遇可跳过状态继续回溯。

递归仅搜索D以前、可用250根窗口内的平台首板；无首次下降、无新峰值、无setup、浅回调可跳过，提前突破停止；可用历史耗尽不等于上市以来无锚点。缺行与官方日历未认证，因此不宣称完整生产递归验收通过。首次下降判C_t<C_(t−1)，等值不触发；严格收盘突破C>P。

## 文件分工

- historical-events.csv / .json：D日原始OHLC、上一可观测原始收盘、D−1背景与D收盘快照；旧短历史输入快照保留审计，不覆盖。
- candidate-classifications.json：432条带版本、时点、完整候选尝试路径和P/L可知日期的记录。
- factor-snapshots-long.csv：优先用于因子对照的长历史暖启动副表；27事件×2时点×14字段=756条，逐值附公式、窗口、单位、覆盖和原因码。数据来自工程师four-case-paths.csv，输入输出哈希见factor-snapshot-manifest.json；扩长暖启动没有扩展事件集合。
- event-price-charts.html：27张截至各自D的价格图；展示候选固定B/5%/不强制新峰值/仅最近。图和当日判断不含后续结果。
- forward-outcomes.csv：135条独立结果（27×1/3/5/10/20根后续可观测日K），收盘收益、最高价与最低价相对D收盘的变化。以复权路径计算，不代表可实现收益；不是回测交易。
- forward-tracking.json：449条后续每日观察，保留D日冻结P，不覆盖D判断；跟踪只描述冻结局部基准的关系，不冒充已定完整多尺度分类。
- manifest.json / raw-price-snapshot.csv：固定输入输出哈希、查询与原始价格副本。

## 因子时点与定义

副表background_D_minus_1截至D−1收盘，event_D_close截至D收盘。position_highlow_240d与position_highlow_250d分开，均为(C_asof−min low)/(max high−min low)，窗口包含asof日，绝不混称位置。暂不声称研究公式已与注册表position_240d逐位认证。

量比=本快照日成交量/此前5根成交量均值，分母排除本日；所以D日量比属于D收盘快照，而背景量比是D−1日量/其之前5根均量。波动率字段是20个日收益的样本标准差ddof=1，不是年化波动率。动量需要n+1根收盘。缺失分别记WARMUP_INSUFFICIENT、ZERO_DENOMINATOR、SOURCE_MISSING。换手率、行业、财务与市场环境保留专属原因码，禁止当前值回填。

D日涨幅是当日已知描述，可后续检验增量作用，不因首板筛选后普遍接近涨停就循环证明分类有效。本批交易所除权昨收缺失，原始价格变化明确使用上一可观测收盘，不能冒充官方涨幅。

## 复权、缺失与复核边界

结构使用固定复权快照；另给P/L按D原始收盘重标尺的值，但重标尺不是点时复权因子完整认证。四股窗口没有验证到除权差异，仍待独立因子审计。历史首板身份未知，所有事件不得混入正式统计。

截至2026-10-23固定截断；22个后续期限不完整，结果为空并带RIGHT_CENSORED原因，不填零、不跨期补齐。期限按可观测个股日K计数，官方交易日及停牌差异未认证，不能直接称严格交易日收益。

自检：432次相同前缀计算比较一致；另检查所有anchor/P_known_at/L_setup早于D、首次突破不晚于D、D−1与D因子时点分离、449条跟踪晚于D、右截断空值。该前缀比较使用同一研究函数，不是独立验证，也不替代未来扰动测试。生产内核61事件测试结论不能套用此候选函数。
