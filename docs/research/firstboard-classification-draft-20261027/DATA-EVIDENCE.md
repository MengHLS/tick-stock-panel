## 2. 复权口径（可核查）

- 前复权实现：`indicators/pipeline.py:246 _apply_adj_factor`，`adjusted = raw × cumprod(≤D) / cumprod(全部)`。
- 因子是事件行（每次除权一条），比值非累积；缺 2018 年以前的事件不影响正确性（分子分母同时约掉）。
- 因此 **该日之后**发生的新除权会改变历史复权价：百分比距离（距前高、回调幅度）尺度不变，**绝对价位 P/L 会变**。台账必须写"复权基准日 = 数据快照日"。
- `close` 为未取整的 float64 复权价，`raw_close` 为交易所两位小数原始价。**复权价不应按 0.01 取整**：它不是交易所报价，取整等于制造伪精度。0.01 只适用于原始价的交易所比较。
- 首板确认的正确基准是原始价：`raw_close >= limit_up_price`，`limit_up_price` 用整数分算术 + 0.005 容差（`price_limits.py:165/229`），不要用复权价判定涨停。
- 结构价格（前高、低点、距离）用同一复权尺度即可，两者数值不同但分类结论一致（已验证 603121：原始 P=19.03，复权 P=11.26，距离同为 +6.88%）。

## 4. 历史 ST：不可认证（两侧都不够）

- 当前平台：`instruments` 只有**当前** `name`，无名称变更史、无 ST 标记列；现名含 ST 者 297/5,889。`price_limits.numpy_limit_pct_vectors` 直接用该名称生成历史 ST 5% 矩阵 → 现在 ST 的股票在历史日也按 5% 判，属于未来信息；反之曾 ST 现已摘帽者历史按 10% 判。
- 旧项目：`research_security_status_history` 只有 ST 区间（841 行 / 734 只），`NORMAL` 行 0 条，`availability` 全 UNKNOWN，`retrievedAt` 集中在 2026-09-06~09 之后；其 `AUDIT-FIRSTBOARD-ROLLING-POOL-RECOVERY-ST-004.md` 已判 `INSUFFICIENT`——窗口内 PIT 一个结论都给不出。
- 结论：**首板认定中的"ST 5% 分支"目前不可认证**。建议分类阶段把 ST 相关事件标 `历史制度未知` 并单列质量原因，不静默按非 ST 处理；要真正修复需 `st_history` 点时数据集（含 NORMAL 行），属系统缺口。

## 5. 停牌与缺行

- 日 K 只存有行日期，停牌日无行；矩阵按时点×标的建网格，缺格为 NaN（`matrix.py:600 float_matrix(default=nan)`）。
- 事件链 kernel 要求 `price_valid[anchor..T]` 全为真，否则整条候选记"结构不完整"（`factors/event_chain.py:211`）。**不会跨停牌拼接路径**，也不会把停牌当平收。这一点与"停牌致首板后第一根下跌 K 跨日"的担心相反，属可验证的好性质，应有测试固定。
- 但"结构不完整"目前与"数据缺失"共用阶段 1，无法区分是停牌、上市不足还是价格非法——分类规格要求单列质量原因。
- 无官方历史交易日历（指数仅 2025-10-27 起），跨年缺失判定只能依赖全 A 并集日历；若某日全市场无数据（休市），并集也不会误判为停牌。

## 6. 历史股票池

- `instruments` 是单快照（`as_of` 2026-10-26），无退市日字段；日 K 中有 230 只最后交易日早于 2026-09-01，说明**退市股日 K 部分保留、但维表无退市日期**，无法按 as-of 还原历史可交易池。
- 该限制已在 `docs/factor-system-design.md`（§数据契约、`delisted_kline`、`st_history`）登记为已知缺口。
- 对分类的影响：2019 年以来用例的"无前次首板"可能是**上市晚而非无首板**——已验证 603448 全库仅 31 根 K 线、001328 仅 859 根。此类必须记 `覆盖不足`，不能记"2019 以来无前次首板"。

## 7. 12 例逐例核对（v2，2026-10-28 更正）

**更正记录**：v1 的复算脚本在找"首根收盘下降"时误比较了 `raw_low` 而不是 `raw_close`，导致 P 取到下降日之后的高点、L 取到突破后低点。验证员用同一面板指出并复现了草稿值，本节的数字按正确判据重算；v1 原表保留在 §7.3 供审计。

判据（初稿 v0.2 字面规则）：i = 第一个 `close[i] < close[i−1]`；P = `max(raw_high[锚点..i−1])`（下降日不计入）；j = 第一个 `close[j] > P`；L_setup = `min(raw_low[i..j−1])`，无突破则到 T−1；L_breakday = `raw_low[j]` 单列。

读法三条：

1. **草稿 P 的口径可以反推出来了**：001328（33.06）、002687（6.62）、002322（13.33）三例的草稿 P 都恰好等于**首根下降日当天的最高价**；按初稿"下降日不计入"则分别为 32.60 / 6.57 / 13.08。这说明草稿数字来自"下降日高价计入 P"的变体——正是待裁决的那条规则，也因此这三例天然构成该规则的真实分界样本，不必另外构造。002612 / 002945 / 603286 / 603121 两口径同值，不能用来区分。
2. **002241 是 P 值口径差**：草稿 P=36.72 等于 2025-08-29 收盘，而当日最高 37.17；legacy L=19.50 落在首次突破 2025-09-30 之后，属 L_after。两处都不是数据问题。P 口径未定前，该例"距 P"在 −37.8%（最高价基准）到 −43.2%（收盘价基准）之间摆动，不能当已定形态。
3. **000559 仍无法解释**：02-11 最高 20.88、收盘 20.21，窗口最高收盘 20.31，legacy 20.6503 三个都不等于，且带 12 位小数（同例 C、L 都是两位）。这不像规则变体，需回旧项目取该字段的计算来源。

## 8. 待决 / 需 Chief 转系统缺口

1. **创业板 10%→20% 历史切换**（2018-01-08~2020-08-21）：代码缺口，影响该区间 300xxx 首板判定；验收＝构造 2020-08 前后创业板用例，涨停判定随时间切换且不回归。
2. **历史 ST 点时数据集**（含 NORMAL 行与 `as_of`）：两侧均不可认证；验收＝给定 (symbol, date) 返回 NORMAL/ST/UNKNOWN 且 UNKNOWN 可计数，报告带降级注记。
3. **退市股维表**（`delist_date`）：影响历史可交易池；验收＝按 as-of 还原的池与当日实际有行情标的可对齐。
4. **历史交易日历**：指数仅 1 年，跨年缺失/停牌区分依赖并集日历；验收＝提供 2018 起交易日历或确认并集日历为口径。
5. 质量原因分列（缺行/上市不足/非法价/公司行动未认证/历史制度未知）需进分类输出字段，不能只落在阶段 1。

## 9. 制度问题的影响面（v2：按可核查定义重算，不称"可用"）

### 9.1 候选事件集的生成口径

| 项 | 取值 |
|---|---|
| 来源表 | `kline_daily_enriched`（`D:\TSP\data`） |
| 筛选 | `consecutive_limit_ups == 1` |
| 区间 | 2018-01-08 ~ 2026-10-27（含端点） |
| 去重键 | `(symbol, date)`；实测总行 9,728,665 = `count(distinct (symbol,date))`，候选集 102,238 亦等于去重计数，**无重复行** |
| 板块归属 | 按代码前缀：688/689=STAR、300/301/302=GEM、`.BJ`=BJ、其余=MAIN |
| ST 归属 | `instruments` 中**当前**名称含 `ST`（297/5,889），非历史 ST |

⚠ 前提：`consecutive_limit_ups` 本身由平台生成（`raw_close >= limit_up_price`，涨停幅度取自当前名称 ST 判定 + 前缀静态板块 + 上市初期无涨跌幅窗口）。因此 102,238 是**平台口径的候选首板事件**，不是已认证首板全集；制度缺陷同时影响它的识别与遗漏。

### 9.3 剩余集合

剔除现名含 ST（16,822）与早期创业板（541，其中 12 个已含在前者）后剩 **84,887** 个事件。该集合应标记为**"待认证候选"**——既未完成历史 ST 认证，也未完成板块制度认证，只是暂时没有已知污染来源；不能称"仍可用"或"主样本"，也不能据此给出类别数量或表现。

在制度认证（`st_history` 点时数据集 + 板块幅度按日期切换）到位前，任何分类统计都须同时报：纳入数、排除数、未知数。
