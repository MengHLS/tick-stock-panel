### 3.3 `E4-A3` 分段一致 + 切点无假月末（可执行断言）

```python
AXIS = load_trading_calendar()                      # 2,141 天
WIN  = [d for d in AXIS if date(2019,7,1) <= d <= date(2026,10,30)]   # 1,779 天
c    = [WIN[int(len(WIN)*q)] for q in (0.25, 0.5, 0.75)]              # 2021-04-27 / 2023-02-28 / 2024-12-26
SEG  = [WIN[0:c1], WIN[c1:c2], WIN[c2:c3], WIN[c3:]]                  # c1,c2,c3 = 上述切点索引

# ① 带「多取一个周期尾部」的分段（契约原文要求）
for kind in ("month_end", "week_end"):
    whole = run_axis(WIN, kind)                       # 整段计算
    union = set()
    for lo, hi in SEG:
        tail = month_tail(hi) if kind == "month_end" else week_tail(hi)   # 该月/该 ISO 周的最后一天
        union |= {d for d in run_axis(days_between(lo, min(tail, AXIS[-1])), kind) if lo <= d <= hi}
    assert union == set(whole)
    assert len(whole) == (88 if kind == "month_end" else 376)

# ② 测试有效性反证：无尾随的 naive 分段必须红，且多出的恰好是那 3 天
naive = set()
for lo, hi in SEG:
    naive |= set(run_axis([d for d in WIN if lo <= d <= hi], "month_end"))
assert naive - set(whole) == {date(2021,4,26), date(2023,2,27), date(2024,12,25)}   # 91 vs 88
assert len(naive) == 91
# week_end 同型：len(naive_we) == 379，差集同上 3 天

# ③ 切点：月中切点及其前一日都不是调仓日
assert is_rebalance(date(2021,4,27)) is False and is_rebalance(date(2021,4,26)) is False
assert is_rebalance(date(2024,12,26)) is False and is_rebalance(date(2024,12,25)) is False
# 2023-02-28 本身就是月末 → 它必须是调仓日（不套用上式），但它的前一日不能是
assert is_rebalance(date(2023,2,28)) is True
assert is_rebalance(date(2023,2,27)) is False
```

**为什么必须写成「带尾 + 反证」两段**：只写 union == whole，实现可以两个方向都错（既不切段也不算尾）而互相抵消；只写 naive 会红，实现可以故意不带尾。两段都写，才卡住「切段实现」与「非切段实现」给出同一答案。

### 3.4 `E4-A4` 节假日月 —— **契约此条与真盘相反，必须先改契约**

契约 v0.12 `§5.6` 与 v0.13 `:605` 都写：「春节所在月（如 2024-02）`month_end` == **节前最后一个交易日**，`2/29` **不存在于轴上**」。

真盘实测（`kline_daily_enriched`）：

- 2024-02 轴上交易日 **15** 天：`02-01 … 02-08`、`02-19 … 02-29`；
- `2024-02-09`（除夕）**不在轴上**（休市 02-09 … 02-17，02-19 复市）；
- `2024-02-29`（周四，闰日）**在轴上**，且是 2024-02 的 `month_end`；
- 节前最后一个交易日是 **`2024-02-08`**，不是 `2024-02-29`；
- 该周（`2024-02-05 … 02-08`，四个交易日）的 `week_end` 是 **`2024-02-08`**。

→ 按契约字面写的测试**必然失败**（`2/29` 明明在轴上，`month_end` 也不是节前最后一日）。**这是 P0-2**：不改，B4 返工只能交一份红。建议改写为：

```python
# E4-A4（改写版）：春节月 = 15 个交易日 + 闰日是月末 + 除夕不在轴
feb = [d for d in AXIS if d.year == 2024 and d.month == 2]
assert len(feb) == 15
assert feb[0] == date(2024,2,1) and feb[-1] == date(2024,2,29)
assert date(2024,2,9) not in AXIS          # 除夕休市
assert date(2024,2,19) in AXIS             # 节后复市首日
assert date(2024,2,29) in AXIS             # 闰日必须在轴上
assert month_end_of(date(2024,2,1)) == date(2024,2,29)     # 月末是 2/29，不是 2/23/2/08
assert is_rebalance(date(2024,2,29)) is True
assert is_rebalance(date(2024,2,23)) is False               # 卡「用节前最后交易日当月末」的错法
assert week_end_of(date(2024,2,5)) == date(2024,2,8)        # 该周只有 4 个交易日
```

### 3.6 `E4-A6` `week_rule` 二选一（可执行断言）——**「3+3」是 3+2**

我按两种规则在整轴与评估窗各算一遍：

| 规则 | key | 整轴计数 | 窗内计数 |
|---|---|---|---|
| `iso_year_week`（正确） | `(d.isocalendar().year, d.isocalendar().week)` | **452** | **376** |
| `dt_week`（常见错法） | `(d.year, d.isocalendar().week)` | **451** | **376** |

**计数在窗内完全相同（376 == 376），在整轴只差 1** —— 所以「计数差异」根本不能当判据，必须比**日期集合**。差集（整轴）：

- `iso_year_week \ dt_week` = `2019-01-04`、`2024-01-05`、`2025-01-03`（**3 个**）
- `dt_week \ iso_year_week` = `2019-12-31`、`2024-12-31`（**2 个**）
- 合计 **3 + 2 = 5**，不是 3+3。（`2025-12-31` 在 ISO 下属 2026-W01、其组内最大日就是它，两条规则都标它，故不进任一差集；`2026-01-02` 不在轴上。）

窗内（`2019-07-01 … 2026-10-30`）：`iso \ dt` = `{2024-01-05, 2025-01-03}`，`dt \ iso` = `{2019-12-31, 2024-12-31}`（2 + 2）。

```python
def week_end_set(days, keyf):
    g = defaultdict(list)
    for d in days: g[keyf(d)].append(d)
    return {max(v) for v in g.values()}

A = week_end_set(AXIS, lambda d: (d.isocalendar()[0], d.isocalendar()[1]))   # iso_year_week
B = week_end_set(AXIS, lambda d: (d.year, d.isocalendar()[1]))              # dt_week

assert len(A) == 452 and len(B) == 451
assert A - B == {date(2019,1,4), date(2024,1,5), date(2025,1,3)}
assert B - A == {date(2019,12,31), date(2024,12,31)}          # 3 + 2，不是 3 + 3
assert len(week_end_set(WIN, iso_key)) == len(week_end_set(WIN, dt_key)) == 376  # 计数不可作判据
assert week_end_set(WIN, iso_key) - week_end_set(WIN, dt_key) == {date(2024,1,5), date(2025,1,3)}
assert week_end_set(WIN, dt_key) - week_end_set(WIN, iso_key) == {date(2019,12,31), date(2024,12,31)}

# 显式入参：不得隐默默认
with pytest.raises(TypeError):
    build_rebalance_axis(AXIS, week_rule=None)   # 或 (缺参)
for rule in ("dt_week", "iso_year_week"):
    build_rebalance_axis(AXIS, week_rule=rule)   # 两个取值都可跑，各自产出上面的集合
```

**这条同时废掉 brief 里「两法跨年 3+3 逐日清单」的写法**：按 3+3 写的测试会要求一个不存在的第 6 天，任何正确实现都过不了。
