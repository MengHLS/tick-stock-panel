## 5. 「4 个撞名活配置接线后会不会被打成 400」

### 5.1 事实（本机实测）

| 量 | 值 |
|---|---|
| `gate._column_universe()` | **68** |
| `custom_signals.ALLOWED_FIELDS` | **54** |
| `boll_lower` / `boll_upper` / `ma20` / `ma60` | **四者同时在两集合内** |
| `assert_factors_usable(19 名, "production")`（真盘 facts） | `blocked = 4 × **FS01**`，`status=None` |
| 同一 4 名按 alias 面 | **不出 FS03**（其 spec 无 `alias_of`） |

### 5.2 结论：会 400，但原因不是 alias

1. 运行时这 4 个名字是**列**：`custom_signals._parse_right`（`:175-215`）对「裸名命中 `allowed_fields()`」直接返回 `("field", name)`；`left` 侧名字（`:459`）也按列取。所以 7 条活信号（`boll_breakdown_lower` / `boll_breakout_upper` / `ma20_breakdown` / `ma20_breakout` / `ma_dead_5_20` / `ma_golden_20_60` / `ma_golden_5_20`）今天跑的是列，不是因子。
2. 闸门是 **factor-first**（`gate.py:229-233` `RegistryFacts.facts`：`spec is not None` 时列分支**永不求值**）。名字撞上注册表就按因子判 → `status=None` 按 `draft` → **FS01**。
3. `shadow=False` 时 `blocked` 非空即抛 `GateError` → 接线后是 **400**。

**关键点：这与 B0b-1 是否交付无关。** 4 条是 FS01（status 面），不是 FS03（alias 面）。B0b-1 只补 `alias_of`，**不会**消掉这 4 条，也不会新增它们。任何一次「把引用名原样喂给闸门」的接线都会触发。

### 5.3 附带事实（须登记）

8 只 canonical `uf_*` 当前全部 **FS01**（`status=draft`）。即：**即使接线时正确声明 `namespace="column"`，任何真的去引用 `uf_vol60` 的配置也会 400。** 这是 §7.15 P2「14 只全无 status」的后果，不是 alias 问题。

### 5.4 不靠改闸门语义的三条处置

| 方案 | 可行性 | 代价 / 风险 |
|---|---|---|
| **(b) `namespace` 入参**（架构师 `CLAUSE_NAMESPACE_COLLISION` §2.2） | **首选，可判** | 6 个接入点必须逐个传，**漏传不报错**，只退回 fail-closed（4 条重现）→ 必须配一条影子期「block 集合逐 id 相等」的比对把它变成可指认的差异 |
| 豁免白名单（把 4 名写进 allowlist） | 可做 | **等于改闸门语义**，且永久免检 `ma20`；架构师 §2.5 已以同类理由否掉 column-first，白名单同一病 |
| 迁移窗口（4 个活配置裸名 → `field:` 前缀） | 可做，但换的是配置不是语义 | 需重存 4 个配置 + 影子比对 + `F-A29` 的「逐位相同」验证；裸名本就是 `custom_signals` 的容错分支（`custom_signals_ai.py:88` 明令「严禁裸写」），迁移顺带清技术债 |

### 5.5 建议排期（给开发经理）

**B0b-1 拆两步，不可一步到位接线：**

- **Step A（先做，可独立验收）**：载体（`FactorSpec.alias_of` / `strategy_usable` + pack `_ALIAS_OF`）+ `namespace` 入参（keyword-only、缺省 `"factor"`）+ FS04 改 `GateError` + `EXEMPT_KINDS` 黑名单。**生产调用点仍为 0**。验收用 §3 的 A1–A7。
- **Step B（后做）**：6 个接入点接线，**逐点传 `namespace="column"`**。接线前先 `shadow=True` 跑一轮，断言 `blocked` 集合 == §1.3 的 4 条 FS01（预期值），再由 A9 断言 `namespace="column"` 下 19 名全过；两步都绿才翻 `shadow=False`。
- **前置硬条件**：`namespace` 参数**当前不存在**（`inspect.signature` 实测 `has_namespace=False`）。在它落地前接线 = 7 条活信号立刻 400。
