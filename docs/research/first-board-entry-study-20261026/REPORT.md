# 首板事件链入场研究（2026-10-26）

## 结论先行

这次研究不支持把现有事件链直接解释为可交易优势，也不支持把“降低入场位置”单独当作修复方案。

- 108 个“策略 × 执行约束 × 时段”组合中，只有 1 个组合总收益为正：
  `strict_combined + gap3 + 2024`，40 笔，总收益 `+0.57%`，最大回撤
  `-34.95%`，Sharpe `0.15`。它属于单一年份、小样本结果，不能据此晋升。
- 没有策略在开发期、2024 验证期和 2025-2026 回顾期同时为正。
- 降低入场位置是有效的描述性筛选，但不是收益修复：
  `low_start` 把信号前 240 日位置中位数从原策略的 `69.1%` 降到 `18.7%`，
  全区间仍亏损 `95.28%`。
- `strict_combined` 是损失较小且位置较低的组合，但它仍在中位持仓位置约
  `35%` 时亏损 `84.54%`；在 2025-2026 回顾期亏损 `62.81%`。
- 高位突破对照组 `high_breakout` 全区间亏损 `99.27%`，止损率 `84.50%`，
  这与“高位突破更容易继续上涨”的假设相反。
- 当前瓶颈很可能不只在入场。所有研究的共同退出规则仍是 `-8%` 止损、
  最长 30 个持仓日；代表策略止损率约 `75%-85%`，中位交易收益约 `-8.22%`。

因此，本轮不应发布或晋升任何策略。事件链字段继续保留为描述和审计信息；
下一步应做“入场定义 × 退出机制”的二维研究，而不是继续在入场条件上做单维
参数搜索。

## 研究口径

数据来自当前项目的生产矩阵加载、有效基础过滤、策略叠加条件、T+1 开盘成交
和现有撮合引擎。研究没有另写第二套模拟器，也没有修改数据库。

| 项目 | 口径 |
| --- | --- |
| 股票池 | 当前平台可用历史股票池 |
| 数据生成 | `632eb37529dd4b5896e8d62025d05333` |
| 完整区间 | 2021-10-26 至 2026-10-26 |
| 开发期 | 2021-10-26 至 2023-12-31 |
| 回顾验证期 | 2024-01-01 至 2024-12-31 |
| 后续回顾期 | 2025-01-01 至 2026-10-26 |
| 成交 | 信号日 T，T+1 开盘 |
| 初始资金 | 1,000,000 |
| 最大持仓 | 5 |
| 仓位 | 等权 |
| 成本 | 佣金 `0.02%`、卖出印花税 `0.10%`、滑点 `5bp` |
| 退出 | `-8%` 止损，最长 30 个持仓日；新策略移除排名退出 |
| 时间信息 | 入场特征只使用 T 日收盘及以前；T+1 开盘只用于成交约束 |

所有时段都在期初重新建仓并强制在期末结算，不能把分时段结果简单复利拼接成
完整区间结果。完整区间是独立运行结果，用于诊断，不用于选参。

这不是未经观察的样本外数据。2021-2026 的总体结果在预设本次研究前已经被查看，
因此 2024 和 2025-2026 只能称为时间切分回顾，不应当包装成纯净 OOS。

## 预设策略

| 策略 | 入场定义 |
| --- | --- |
| `legacy_rank` | 原始单因子排名策略，保留原排名退出 |
| `same_entries_fixed_exit` | 原入场和评分，移除排名退出 |
| `strict_event` | 事件链阶段 5：目标首板首次收盘突破前高 |
| `strict_recent` | 阶段 5，锚点不超过 30 个交易日 |
| `strict_context` | 阶段 5，T-1 位置不超过 0.6，T-1 20 日收益不超过 20% |
| `strict_not_extended` | 阶段 5，T 日 MA20 偏离不超过 15%，相对前高不超过 3% |
| `strict_combined` | 最近锚点、低中位、未过热三组条件同时满足 |
| `low_start` | 任意首板，T-1 位置不超过 0.4，T-1 20 日收益不超过 10% |
| `reattack` | 阶段 3/5，近期、低中位、回调 5%-20%、目标不过热 |
| `high_breakout` | 阶段 5，T-1 位置不低于 0.8；高位描述性对照 |

执行约束分三种：

| 执行约束 | 定义 |
| --- | --- |
| `unrestricted` | 不限制实际 T+1 开盘 |
| `gap3` | T+1 开盘相对 T 收盘涨幅不超过 3% |
| `gap3_reference3` | 同时要求 T+1 开盘相对事件链前高 P 不超过 3% |

开盘约束在信号产生后、按实际 T+1 开盘检查；超出范围时拒绝入场，不把成交价
人为截断到限制值。

## 结果

### 完整区间代表结果

收益和回撤均为小数收益率；表中显示为百分比。`位置` 为信号前 240 个有效收盘
计算的位置中位数，`20日` 为信号日 20 日收益中位数，`距L` 为实际开盘价高于
回调低点 L 的中位距离。

| 策略 | 笔数 | 总收益 | 最大回撤 | 止损率 | 位置 | 20日 | 距L |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `legacy_rank` | 852 | -99.43% | -99.50% | 75.94% | 69.1% | 23.5% | 16.8% |
| `same_entries_fixed_exit` | 576 | -97.76% | -98.10% | 81.42% | 66.4% | 22.3% | 16.6% |
| `low_start` | 489 | -95.28% | -95.74% | 77.51% | 18.7% | 2.1% | 14.4% |
| `reattack` | 435 | -96.51% | -97.32% | 80.00% | 35.2% | 11.1% | 12.4% |
| `strict_combined` | 226 | -84.54% | -85.08% | 80.09% | 35.4% | 12.5% | 14.2% |
| `high_breakout` | 555 | -99.27% | -99.31% | 84.50% | 90.5% | 34.8% | 18.6% |

`strict_combined` 的绝对损失最低，说明降低位置、缩短锚点距离和限制过热具有
一定筛选作用。但 `35%` 的位置和 `12.5%` 的 20 日收益仍然没有形成盈利优势。

### 分时段稳定性

下表为 `unrestricted` 执行约束下的总收益。

| 策略 | 开发期 | 2024 | 2025-2026 |
| --- | ---: | ---: | ---: |
| `legacy_rank` | -88.14% | -79.22% | -76.86% |
| `same_entries_fixed_exit` | -84.09% | -69.30% | -66.76% |
| `low_start` | -69.74% | -71.96% | -56.94% |
| `reattack` | -65.71% | -60.08% | -74.45% |
| `strict_context` | -75.52% | -64.16% | -44.45% |
| `strict_combined` | -47.41% | -22.84% | -62.81% |
| `high_breakout` | -92.73% | -54.83% | -80.35% |

开发期表现相对较好的 `strict_combined` 在后两个时段继续恶化。2025-2026
相对最好的 `strict_context` 在开发期和 2024 明显落后。没有稳定的跨期赢家。

### 执行约束

`strict_combined` 三种执行约束对比：

| 时段 | 不限开盘 | 开盘涨幅≤3% | 同时距P≤3% |
| --- | ---: | ---: | ---: |
| 开发期 | -47.41%（92笔） | -42.80%（73笔） | -37.65%（59笔） |
| 2024 | -22.84%（55笔） | +0.57%（40笔） | -2.92%（29笔） |
| 2025-2026 | -62.81%（79笔） | -55.79%（61笔） | -44.86%（44笔） |

对 `strict_combined`，开盘约束在三个时段都减少了损失，并且 2024 的
`gap3` 是全部 108 行中唯一正收益。但该结果只有 40 笔，最大回撤仍为
`-34.95%`，不能视为稳定优势。

执行约束并非普遍有效：

- `reattack + gap3` 在 2025-2026 的收益为 `-78.73%`，比不限开盘的
  `-74.45%` 更差。
- `same_entries_fixed_exit + gap3` 在 2025-2026 为 `-74.04%`，比不限开盘的
  `-66.76%` 更差。
- `same_entries_fixed_exit` 的完整区间位置中位数在 `gap3` 后反而从 `66.4%`
  升到 `71.6%`。这说明“过滤掉部分高开”不保证最终入选股票的位置更低。

因此，实际开盘约束可以改变候选和结果，但不能把它简化为“少做几笔就是改善”。

## 对四个研究问题的回答

1. **事件链是否继续作为描述信息**

   是。阶段、锚点、P、L、回调、首次突破和递归原因继续保留为描述性字段，
   不应单独当作收益排序因子。阶段 5 的首板位置中位数为 `76.4%`、20 日收益
   中位数为 `26.3%`，说明“首次收盘突破”本身天然偏向已经上涨的目标。

2. **低位首板、回踩回攻、首次突破哪个更好**

   没有证据证明三者中任何一个已经构成稳定盈利入场。低位首板有效降低了
   位置和短期涨幅，但仍大幅亏损；回踩回攻距离 L 更近，但没有改善跨期稳定性；
   首次突破的原始阶段 5 明显偏高。

3. **次日实际开盘约束是否有用**

   对部分定义有帮助，尤其是 `strict_combined`，但不具备普遍性。开盘涨幅约束
   必须作为执行方案的一部分单独报告，不能继续假设信号收盘价成交。

4. **分时段后是否仍稳健**

   不稳健。没有组合在三个时段同时盈利；唯一正收益来自单一年份小样本。
   当前结果不足以支持任何策略发布、监控上线或资金配置。

## 统计与验证

- `results.csv`：108 行，策略、执行约束和时段的组合键全部唯一。
- `runs/`：108 个独立运行 JSON。
- 所有运行均满足 `before = accepted + rejected`。
- 逐笔交易均可回连到冻结信号日事件描述。
- `manifest.json` 验证通过：
  - `source_unchanged = true`
  - `generation_unchanged = true`
  - `trial_rows = 108`
  - `all_trades_matched = true`
  - `entry_cap_conservation = true`
- 研究脚本 Ruff 检查通过。
- 针对性测试实际结果为 `34 passed, 1 failed`。唯一失败是矩阵撮合与旧撮合
  在交易记录、净值和回撤都一致后，执行统计字典多了两个零值键
  `buy_open_gap`、`buy_prev_day_change`。该失败是统计契约差异，不是本研究的
  成交或收益差异，但在发布策略前仍应修正。

注意：结果 CSV 的 `profit_factor` 在当前引擎中表示“平均盈利单收益率 /
平均亏损单收益率”，不是“总盈利金额 / 总亏损金额”。例如 `legacy_rank`
的该值为 `2.00`，但总盈利金额只覆盖约 `55.9%` 的总亏损金额，因为亏损交易
占多数。不能只看这个字段判断策略有效。

## 限制

- 股票名称、股本、ST 和上市历史使用平台当前可获得的维度，历史生存偏差、
  历史 ST 状态和历史股本口径没有独立认证。
- 三个时段都已被研究过程观察，不是纯净样本外。
- 研究只覆盖股票日线，不包含盘中冲高回落、封板排队和分钟级成交。
- 本轮没有穷举退出参数。当前统一的 `-8%/30日` 退出是共同基线，不代表最优
  退出，也不能用它完全否定入场信息。
- 结果只说明当前实现和当前数据上不支持晋升，不构成未来收益判断。

## 下一步

优先研究退出和持有机制，而不是继续搜索入场阈值：

1. 固定本轮相对最好的 `strict_combined` 与 `low_start` 入场，分别比较
   固定持有、结构失效、移动止损、时间退出和盈利保护的差异。
2. 对入场与退出做二维分组，避免用同一个 `-8%` 止损掩盖入场差异。
3. 将“少交易”拆成候选排除原因，分别检验高开、过热、高位和结构失败的贡献。
4. 在下一段真正未观察的数据积累前，不根据本轮单一正收益行调整生产策略。
