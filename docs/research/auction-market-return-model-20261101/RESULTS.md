## 1. 结论

本轮增加独立的 D+5 市场绝对收益模型。模型只使用 D-1 已完成的上证指数
趋势、动量、波动、回撤、量额比和上涨日占比，预测每个日期与缺口桶的
全市场 D+5 基准净收益。

主变体在经济决策中要求：

```text
预测市场基准收益 + 训练期选股增量 > 0
```

结果：

- 主变体保留 730 个事件，平均 `0.647 个/交易日`；
- 事件净收益首次进入正区间，为 `+0.076%`；
- 事件增量 `+0.578%`，95% 区间
  `+0.061% ～ +1.101%`，下界首次转正；
- 组合收益为 `-0.891%`；
- 最大回撤为 `-16.001%`；
- 无缺失盯市；
- 预注册门槛仍有组合收益和最大回撤两项失败。

市场绝对收益模型确实包含可用的样本外信息。加入训练期选股增量后，事件净收益
和增量区间均通过，但组合仍未跨过盈亏平衡，最大回撤距门槛约 1 个百分点。
本轮不因接近通过而调整阈值、特征或窗口。

## 2. 预注册规则

### 2.1 市场目标

对每个交易日和缺口桶，计算全部可解析主板事件的 D+5 平均净收益：

```text
market_target_return =
  mean(D+5 net return of eligible events on date × gap bucket)
```

训练时只使用 `exit_date <= train_end` 的已成熟事件。目标在训练时截尾到
`[-20%, +20%]`，测试指标使用原始基准收益。

### 2.2 市场特征

所有特征均在 D 日前再滞后一个已完成指数交易日：

- 1、5、20、60 日指数收益；
- 5、20、60 日均线乖离；
- 5、20、60 日已实现波动；
- 20、60 日距滚动高点回撤；
- 5 日/20 日成交量比和成交额比；
- 20 日上涨日占比；
- 两个缺口桶哑变量。

模型为 Ridge 回归，`alpha=10.0`，使用从 2020-01-02 起的扩展训练窗口，
逐年验证 2022～2026 年。

### 2.3 训练期选股增量

每折重新执行冻结的因子准入、聚类、综合排名和分数带选择，只使用训练期内已到期
标签，计算训练名单相对同日、同缺口桶基准的平均增量收益：

| 验证折 | 训练期选股增量 |
|---|---:|
| 2022 | +0.666% |
| 2023 | +0.704% |
| 2024 | +0.774% |
| 2025 | +0.790% |
| 2026 年 1～8 月 | +0.735% |

该值只用于把预测市场基准转换为股票策略的预期绝对收益。验证期不重新估计，
也不根据验证结果调整常数。

### 2.4 冻结变体

| 变体 | 规则 |
|---|---|
| `always_full` | 不增加市场过滤 |
| `trend_vol_gate` | 原 D-1 趋势与波动硬闸门 |
| `market_positive_gate` | 预测市场基准大于 0 |
| `market_top50_gate` | 预测市场基准高于训练期预测中位数 |
| `market_plus_alpha_gate` | 预测市场基准 + 训练期选股增量大于 0 |

主变体在运行前固定为 `market_plus_alpha_gate`。被过滤候选不补位。

## 4. 事件结果

| 变体 | 选中数 | 平均/日 | 净收益 | 增量 | 增量 95% 区间 |
|---|---:|---:|---:|---:|---:|
| 始终满仓 | 1,239 | 1.097 | -0.054% | +0.768% | +0.401% ～ +1.162% |
| 原趋势波动闸门 | 295 | 0.261 | -0.342% | +1.000% | +0.298% ～ +1.806% |
| 市场基准大于 0 | 521 | 0.461 | +0.142% | +0.618% | -0.021% ～ +1.245% |
| 市场预测前 50% | 917 | 0.812 | -0.062% | +0.516% | +0.064% ～ +0.953% |
| 主变体：市场基准+选股增量 | 730 | 0.647 | +0.076% | +0.578% | +0.061% ～ +1.101% |

主变体相对始终满仓：

- 选中事件减少 509 个，降幅 `41.1%`；
- 事件净收益从 `-0.054%` 提高到 `+0.076%`；
- 增量从 `+0.768%` 降到 `+0.578%`，但下界转正；
- 中位净收益从 `-1.042%` 改善到 `-0.874%`；
- 胜率保持在 `41.78%`。

只使用“市场基准大于 0”的诊断变体收益更高，但增量区间继续跨 0。主变体增加了
训练期选股增量后，信号规模和统计稳定性提高，选股收益被更多中性事件稀释。

## 8. 证据限制

- 这是准样本外，不是新锁箱；2022～2026 年历史区间已经被前序研究观察。
- 市场模型使用上证综指作为统一代理，不区分行业、风格和个股 beta。
- 市场目标来自所有合格主板事件的平均 D+5 收益，不等同于指数未来收益。
- 训练期选股增量是历史训练名单的平均值，不是每笔事件的个体条件期望。
- 市场特征和模型族仍在已观察历史上选定，存在研究选择偏差。
- 组合仍使用日线盯市和五分钟容量代理，不模拟盘口冲击、排队和真实成交概率。
- 2026 年只有 1～8 月，不能外推为长期稳定。
