# 首板右尾 v2/V3 动态入场 pilot：No-Go

## 结论

当前 v2/V3/M2B 方案不进入系统主流程或实盘落地。

两轮按月分层样本都没有同时满足右侧改善和左侧控制：

- 第一轮加入 31 个 T 日/决策时点特征后，`MFE>=30%` 从 16.02% 升到
  25.00%，但 `stop_first` 从 33.64% 升到 43.75%；
- 第二轮独立 seed 中，`MFE>=30%` 从 10.37% 仅升到 13.04%，
  `MFE>=50%` 从 3.95% 降到 0%，`stop_first` 从 27.90% 升到 34.78%；
- 两轮平均效用差异的 bootstrap 95% 区间都跨 0；
- 分年份由少数样本驱动，top 事件分别只有 22 和 28 个，可观察标签
  分别只有 16 和 23 个。

因此第 9.4 节的 Go/No-Go 条件未同时满足。该结论针对当前动态 A/B/C、
标签、特征和冻结阈值，不代表所有动态入场或退出方案。

V3 在决策时点增加早盘结构、市场宽度和 T 日量能特征，并把入场与四组
真实退出规则放在同一执行口径下比较。右尾方向仍有局部改善，`tight4_time10`
也显著压低了 `left6`，但两轮种子都没有形成正期望，年度与小样本稳定性
仍不足。V3 结论同样是 **No-Go**，详见下文。

## 数据与执行口径

- 数据目录：`D:\TSP\data`
- 事件宇宙：2020-01-01 至 2026-09-30，76,176 个沪深主板非 ST
  首板事件
- 抽样：每个自然月按 `event_id` 抽取 10 个事件
- v2 seed `20261102`：数据 generation `b051fac3ad684ee8bcd913ba738adfb5`
- v2 seed `20261103`：数据 generation `46d958301dea422886e239407253cc7d`
- 两轮 generation 不同。第二轮启动后，平台仍有一次分钟数据写入，
  因此两轮只能视为不同数据版本下的稳健性检查，不能视为同一冻结快照的
  严格独立复现。
- 规则：动态 A/B/C；E0 固定 T+1 09:35 单独作为同事件基线
- D 规则未纳入：当前没有研究 CLI 所需的标准化 `auctions.parquet`
- 分钟成交：信号后下一分钟开盘；不允许同分钟收盘信号成交
- 成交约束：一字板/涨停锁死、停牌、T+1、跳空止损、跌停延迟退出
- 成本：佣金、最低佣金、印花税、5bp 滑点、容量约束
- 标签：实际入场后 20 个交易日；未成交或不可观察事件的效用按 0 计
- 模型：5 个年度扩展窗口，30 个交易日 purge，事件权重，阈值只用
  训练期冻结

## 设计评价

已正确落地的部分：

- 动态 A/B/C 入场不再固定在 T+1 09:35，而是逐分钟等待触发；
- 信号与成交时点分离，使用下一分钟开盘；
- 一字板、停牌、T+1、涨跌停、跳空止损和成本均进入可执行口径；
- 年度扩展训练、事件权重、purge、训练期冻结阈值已实现；
- 标签按实际入场价和实际成交日重算。

仍未解决的问题：

1. **事件准入和事件内触发被混在一个分数里。**
   模型同时学习“这个事件能否成交”和“这个触发点未来是否强”，两类
   误差叠加后，top 结果不稳定。
2. **标签优化目标与真实退出收益不一致。**
   utility 基于 MFE/见顶顺序，而交易净收益使用固定退出规则。模型可能
   选到高 MFE、同时更快触发止损的事件。
3. **冻结阈值的事件数量不可控。**
   训练期决策分数分位映射到验证期后，分别只产生 22 和 28 个事件，
   不足以支撑每日 2 仓、最多 5 仓的组合约束，也不足以稳定估计年度差异。
4. **样本规模仍不足。**
   两轮 top 标签合计只有 39 个，且数据 generation 不同，不能替代
   每月 20-30 个事件、固定 generation、至少 3 个 seed 的验证。
5. **组合级风险尚未验证。**
   事件模型未通过 Go/No-Go，因此没有继续做资金占用、回撤、市场闸门
   和逐日仓位回放。

## 事件级两阶段原型

进一步实现并实跑了与决策级模型解耦的事件级原型：

- 事件特征只使用 T 日 20 个日频/联动因子；
- 第一层预测事件是否至少有一次可成交（fill gate）；
- 第二层预测未成交按 0 计的策略净收益；
- 选中事件后，执行仍固定为观察期内 A/B/C 的首个实际可成交触发；
- 预注册默认值：fill gate 保留训练预测前 30%，验证期事件预算 10%，
  单日最多 2 个，按直接策略净收益排序。

该原型仍然没有通过经济性检查：

| seed | 策略事件 | 成交率 | `stop_first` | `MFE>=30%` | `MFE>=50%` | 平均策略净收益 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 20261102 E0 | 564 | 77.48% | 33.64% | 16.02% | 6.41% | -1.79% |
| 20261102 事件策略 | 31 | 100.00% | 48.39% | 22.58% | 12.90% | -3.59% |
| 20261103 E0 | 558 | 72.40% | 27.97% | 10.40% | 3.96% | -2.16% |
| 20261103 事件策略 | 31 | 96.77% | 33.33% | 16.67% | 13.33% | -3.61% |

事件策略相对 E0 的 bootstrap 95% 区间：

| seed | 平均策略净收益差异 | `stop_first` 差异 | `MFE>=30%` 差异 |
| --- | ---: | ---: | ---: |
| 20261102 | -1.79pp `[-5.64pp, +2.97pp]` | +14.75pp `[-2.77pp, +32.31pp]` | +6.56pp `[-7.57pp, +21.16pp]` |
| 20261103 | -1.46pp `[-4.45pp, +2.82pp]` | +5.36pp `[-11.30pp, +22.33pp]` | +6.27pp `[-5.44pp, +20.13pp]` |

填充模型本身不是无效的：

| seed | 成交 AUC | Brier | fill gate 事件数 | gate 内实际成交率 |
| --- | ---: | ---: | ---: | ---: |
| 20261102 | 0.86 | 0.09 | 296 | 98.31% |
| 20261103 | 0.83 | 0.10 | 264 | 98.48% |

但预测净收益没有可用的排序能力：

| seed | `expected_net_return` Spearman | 成交后条件收益 Spearman |
| --- | ---: | ---: |
| 20261102 | 0.06 | 0.02 |
| 20261103 | -0.03 | -0.08 |

结果说明：T 日因子可以识别“更容易成交”的事件，但高成交概率不等于高
净收益；把成交过滤和收益排序拆开后，收益层仍然没有找到有效的经济信号。
因此事件级原型也没有进入组合回测。

## V3 特征与退出实验

### 数据与特征

- 新增早盘决策特征：`opening_gap`、首 5 分钟收益/高低点/区间、首 5 分钟
  成交量占比、VWAP 上方分钟比例、锁死分钟比例、当前价相对首 5 分钟高点、

### V3 Go/No-Go

| 条件 | 结果 |
| --- | --- |
| 事件 Top 10% 的 `stop_first` 明显低于基准 | 未通过：两轮均更高，区间跨 0 |
| `MFE>=30%` 明显高于基准 | 未通过：增量只有 +2.63pp/+0.99pp，区间跨 0 |
| 正期望且回撤可接受 | 未通过：成交后净收益为 -4.12%/-4.29%，组合回测未启动 |
| 分年份不依赖单一年份 | 未通过：Top 标签为 53/44 个，年度方向仍不一致 |
| 跳空/一字板/停牌修正后仍成立 | 未通过：执行修正确实启用，但没有形成稳健经济优势 |

最终结论仍为 **No-Go**。`tight4_time10` 只能作为后续退出实验的候选，
不能直接作为实盘或主流程规则；D 规则、历史 depth5、组合回撤和市场闸门
仍未完成验证。事件级 Top 10% 复核排除了“15/24 个事件造成全部假阴性”
这一解释：扩大诊断样本后，策略仍未通过经济性检查。

## 下一轮建议

1. 暂停 v2/V3 决策分数、事件级收益排序和退出变体进入主流程，不把研究
   排序或 `tight4_time10` 当作实盘信号。
2. 真实事件级 Top 10% 已完成复核，不再把旧 15/24 个冻结阈值事件当作
   Top decile 结论；也不再在同一 T 日因子集上调阈值或继续堆叠排名层。
3. 补齐历史盘口/封单质量数据后，再验证成交概率与经济收益冲突是否能被
   盘口结构解释；在此之前不把 depth5 当作可用特征。
4. 在固定 generation 下重跑每月 20-30 个事件、至少 3 个 seed，按事件
   和日期做 cluster bootstrap；seed 20261102 的动态/E0 差异必须先消除。
5. 只有收益层在事件级和组合级都显示正期望、左尾和年度稳定性通过后，
   再执行逐日最多 2 个新仓、最多 5 仓、市场状态闸门、资金占用和成本
   后的组合回测。
