# 前端扩展目录

每个子目录一个 `extension.tsx` 注册清单，构建时自动发现挂载，无需修改核心路由和导航文件。清单保持轻量：路由与导航同步注册，页面实现放在同目录的 `Page.tsx`，使用 `React.lazy` 按访问加载：

```text
frontend/src/custom/<namespace>/extension.tsx
frontend/src/custom/<namespace>/Page.tsx
```

- **摘除**：删除目录即整体卸载该页面；**导入**：把目录复制进来重新构建即可。
- 冲突（路由/ID 撞车）由扩展注册表在启动时检测，冲突的扩展整体拒绝（原因输出在浏览器控制台），不影响核心页面。

## 目录现状

官方扩展页面落在本目录（id 前缀 `official.`），整目录可独立摘除或导入。旧的单文件扩展仍兼容，但其全部依赖会参与启动加载。

| 目录 | 页面 |
| --- | --- |
| `stock-analysis` | 个股分析 |
| `limit-ladder` | 连板梯队 |
| `concept-analysis` | 概念分析 |
| `industry-analysis` | 行业分析 |
| `industry-chain` | 产业链分析（多级导图 + 股票关联） |
| `financials` | 财务分析 |

| `abnormal` | 异动监控 |

| `review` | 复盘 |

产业链分析将 AI、国产半导体、光通信、MLCC、PCB 和新能源产业链作为独立视角维护。AI、国产半导体、光通信、MLCC、PCB 归入“硬科技底座”；AI 链只保留 AI 需求切片，并通过节点说明引用完整的光通信、MLCC、PCB 和国产半导体链。AI 服务器进一步区分品牌服务器、ODM/代工、主板/加速卡、连接器结构件、测试和待核验配套。同一股票可跨链关联，每处理由、来源与核验状态独立保存，并通过“主营/产品、供应配套、题材线索”标明归属依据。股票关联面板展示其他产业链中的完整节点路径，可点击切换查看。只有一条链的分类在画布中自动省略，避免“人工智能 → AI 产业链”重复。

脑图只展示产业环节。点击末级环节或节点上的「股票」按钮，在右侧查看股票名称、代码、关联理由、归属依据与核验状态；同一股票去重展示，保留不同环节的独立理由，可筛选和编辑。退市、北交所和 ST 股票不进入脑图计数、搜索和右侧列表。题材线索显示在右侧股票标题下方；K 线下方展示最新一期基础财务指标。右侧列表支持按主营/产品、供应配套、题材线索、参股、合作、传闻等关联性质筛选，并可仅看已核验关联；参股/合作/传闻标签按关联理由与备注关键词识别，仅作线索归类，不替代财务或公告核验。历史涨停题材备注支持扩大时间窗口回溯，会替换旧的机器生成块并保留用户手写备注。搜索股票会定位所属环节并打开对应列表。展开、折叠以点击节点为锚点，保留缩放比例；只有首次载入或主动适应、恢复视图才自动调整全图比例。

**新装用户默认隐藏这些页面**，在 设置 → 菜单设置 一键开启；老用户升级自动保持原有菜单位置与排序。

## 不想重建宿主？用页面插件

若目标是把页面打包成产物、在运行中的面板上直接上传使用（本地 / Docker / 桌面端一致），走**页面插件**：用 [`frontend/page-pack-template`](../../page-pack-template) 打包单文件 ES 模块，在 设置 → 页面插件 上传，刷新生效。契约与边界见 [`docs/page-sdk.md`](../../../docs/page-sdk.md)。
