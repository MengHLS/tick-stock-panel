## 2. 根本测不了的策略族（原因：数据不存在，或拿来回测就含未来函数）

### F1 价值 / 估值因子
BP、EP、PB-ROE、股息率、EV/EBITDA。
**为什么不能测**：所有估值因子都需要「历史股本 × 历史价」。而 `financials/shares` **空目录**，`instruments.total_shares` 是 `as_of=2026-11-05` 的**当期快照**，`metrics.bps/eps` **只有 2 期**（2026 年下半年）。用当前股本乘 2019 年的价格，等于把 2026 年的股本结构搬到 2019 年——典型的未来函数。
**可行边界**：只能做 2026-11 之后的前瞻跟踪，不能做任何历史回测。

### F2 质量 / 成长因子的**全期**版本
ROE、毛利率、净利率、应计、现金流质量、营收/利润增速。
**为什么不能全期测**：指标本身能算，但**公告日**决定了 PIT 可用性：资产负债表公告日从 2022-12-29 开始，利润表与现金流量表从 **2025-04-25** 开始。ROE、毛利率、应计都依赖利润表/现金流 → **PIT 只能在 2025-04 之后构造，约 1.5 年，不足一个完整牛熊**。
**可行边界**：只靠资产负债表的比率（资产负债率、资产增速、应收占比）可从 2022-12 起测（约 3.8 年），但 T1（2019-07 ~ 2022-12）全空白，无法与价格类策略同窗口对比。

### F3 行业中性 / 行业轮动 / 行业动量 / 行业分层归因
**为什么不能测**：行业归属只有 6 天快照（面板内 5 天，0.2335%），且快照行只有日期、**不记录「何时可知」**。任何跨年行业回测都必须用当前行业分类去回填 2019 年，这是未来函数。`CAPABILITIES.md` 同样结论。

### F4 指数增强 / 指数成分轮动 / 基准对齐与跟踪误差
**为什么不能测**：`kline_index_daily` 有指数价格，但**无历史成分股与权重**。没有成分股就无法做「在指数内选股」「行业/个股权重偏离」「跟踪误差最小化」；用今天的成分股回测 2019 年同样是未来函数。

### F5 ETF / LOF / 可转债轮动与套利
**为什么不能测**：`kline_etf_daily` 与 `kline_etf_enriched` **0 分区**（0 字节）。有 `instruments_etf` 清单但无任何行情，连基准净值都无法构造。可转债：数据目录里根本没有对应分区。

### F6 事件驱动族
盈余公告漂移（PEAD）、业绩预告、股东增减持、并购重组、指数调样、龙虎榜跟单、涨停板事件。
**为什么不能测**：事件时间轴不完整——龙虎榜 1 天、`depth5` 4 天、利润表公告日最早 2025-04-25（PEAD 至少需要 5–10 年公告日序列才有一半统计功效）。

### F7 停牌 / 退市清算类
「停牌股复牌后溢价」「退市整理期博弈」「暂停上市套利」。
**为什么不能测**：无停牌表、无退市记录，`security_lifecycle_coverage = unknown`。既无法确定某天到底是停牌还是数据缺失，也无法给退市清算损失定价。

### F8 融券/多空/配对交易
统计套利、配对交易、市场中性、多空对冲。
**为什么不能测**：账户模型只做多，无融券成本、无可借券源、无保证金。只能测多头腿，**测出来的 Sharpe 不能当市场中性策略的 Sharpe 用**（它含市场 beta）。

## 3. 可测但精度受限（属「本轮未做」，不是「根本不可测」）

| 族 | 限制 | 可行版 |
| --- | --- | --- |
| F9 规模因子（SMB）/小市值轮动 | 无历史股本，只能用当期 `total_shares` | 改为「成交额/流动性分层」代理（本轮的 C00 就是流动性对照） |
| F10 分钟级/日内（ORB、VWAP、日内反转） | `kline_minute` 2017 起存在，但撮合矩阵是日线 | 需另建分钟矩阵（工程量，不是数据缺失） |
| F11 波动率目标/风险平价带杠杆 | 无融资成本、无杠杆账户 | 只能做「降仓版」，目标波动只能向下调 |
| F12 北向资金 / 融资余额 / 分析师预期 | 数据根本不存在 | 不可做，也不属 F9–F11 的「受限」 |

## 4. 直接结论

在这套数据的现有边界下，**能同时满足「无未来函数 + 覆盖 2019–2026 全期 + 可成交性可验证」的策略族，只有一类：日频、价格与成交量驱动、仅做多、集中持仓的策略**（趋势/突破、短期反转、交易型低波动等截面因子、宽度择时）。

其余七类（F1–F8）**不是「测了不行」，是「测不了」**。任何报告把它们写成「已验证无效」或「已验证有效」都是错的。

> 与目标的关系：「利用各种公开策略直到找到一个稳定盈利的策略」这个目标，在本数据上能实际搜索的空间，比公开策略文献的总量小得多——文献里最稳定的那一大块（价值/质量/事件/指数）恰好是这里测不了的那一块。
