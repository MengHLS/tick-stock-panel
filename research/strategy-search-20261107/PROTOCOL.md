## 0. 冻结声明（先读这一节）

### 0.1 本协议约束什么

1. 本协议**约束此后**（v2 冻结之后）产生的每一次回测运行，不追溯授权此前结果。
2. 只有同时满足下列三条的 run 才算 **确证性（confirmatory）**：
   - run 文件 mtime **晚于**本文件 mtime，且晚于 `STRATEGIES.md` 中该策略条目的最后一次修改；
   - run 记录里的 `scripts/*.py` sha256 与 `FREEZE.json` 一致（见 §9 R2）；
   - 该策略的 key 在 `STRATEGIES.md` 中已存在（先写规格、后跑）。
3. 不满足的 run 一律标 `exploratory`，**只能用于发现问题，不能用于验收、不能用于宣称有效**。

## 1. 目标与非目标

- 目标：在现有撮合与数据下，用统一口径判断「某条公开策略的固定形式在 A 股主板日线上是否有可交易的正期望」，并给出**可核**的证据链。
- 非目标：寻找最优参数（v2 仍不做参数寻优）；证明任何策略能稳定盈利。**本协议不构成盈利承诺**。
- 判定优先于结论：宁可 0 个候选，也不放宽门槛。**v2 的门槛只允许经由新版本号提高或降低，不允许在本文件里改数字。**

### 6.3 N 对门槛的影响（DSR 的零假设线）

| N | SR0（日频） | SR0（年化） |
| --- | --- | --- |
| 12（v1 口径） | 0.0476 | 0.756 |
| **15（v2 基线）** | **0.0506** | **0.804** |
| 20 | 0.0544 | 0.863 |
| 30 | 0.0593 | 0.941 |

## 7. 成本与滑点原则（与 v1 相同）

- 主结论以 10bp 为准；30bp 作耐受性；gross 仅诊断，**不得**作为结论。
- 仅零成本为正、10bp 为负 → 判「被成本吞噬」，不得辩称「实盘滑点更低」。
- 入场跳空单独统计（`results/entry_gaps.json`），是「收盘信号 + 开盘成交」的隐性成本。

## 8. 多重检验控制（不变式）

- Bailey & López de Prado (2014) Deflated Sharpe Ratio：
  `SR0 = sqrt(V[SR]) · [(1−γ)·Φ⁻¹(1−1/N) + γ·Φ⁻¹(1−1/(N·e))]`
  `DSR = Φ( (SR − SR0)·sqrt(n−1) / sqrt(1 − γ3·SR + ((γ4−1)/4)·SR²) )`
- 门槛：**DSR ≥ 0.95**，`N` 取 §6 的累计值。
- 已知局限：`V[SR]` 用本批试验的 Sharpe 方差近似；若真实搜索空间远大于 15，SR0 被低估 → **登记纪律比公式更重要**。
