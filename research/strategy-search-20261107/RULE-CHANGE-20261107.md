# 规则变更登记：策略因子化（2026-11-07 起生效）

来源：MausBot 转达的团队规则变更（自 2026-11-07 生效）。本文件只记录**对我的交付物边界的影响**与既有产物的重新定性，不重复规则原文。

## 1. 我的角色边界（自今日起）

| 我可以 | 我不可以 |
| --- | --- |
| 出策略规格：因子组合表达式 + 参数 + 判据 | 写策略实现代码（含 `matrix_strategy` 插件） |
| 在独立研究目录做探索性复算与独立验证 | 修改 `backend/` 任何文件、正式信号链、回测引擎、API |
| 核对生产代码（只读）以定位口径矛盾 | 以"研究脚本"形式交付可上线的正式实现 |
| 给因子工程师提因子需求与口径要求 | 自己定义并注册因子（因子定义权在因子工程师） |

需要新因子 → 提需求给因子工程师；系统能力不足 → 因子工程师出缺口规格 → 总体规划负责人排期 → 系统架构师定契约 → 系统开发工程师实现 → 独立审核工程师验收。我不跳这条链。
