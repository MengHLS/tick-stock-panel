## 7. 候选评估：S07 截面低波动

> **2026-11-07 v1.1 追加：本节全部数字已作废（`status=void`, `caliber=research-v0-rank`），见 §11。** 下面的「证据强度：弱 / 研究线索」是在错口径下得出的判断，其证据集（选中的股票）不是池内低波动 10% 分位，因此**不得作为继续这条线的依据**；重验顺序与判据见 `caliber-decisions-20261107.md` §7.4（S07 → S11 → S12 → S10 → S06）。

**证据强度：弱。建议不作为实现候选，只作为下一轮研究线索。**

支持它的：
- OOS +31.8%（年化 +7.8%）、Sharpe +0.97；30bp 情景下仍有 OOS +22.1% / Sharpe 0.71，成本耐受性好（年换手 9.4x，是全场最低之一）。
- 相对等权基准 OOS 超额约 +10pp/年，不是"市场 beta"能解释的。
- 入场跳空仅 +0.04%，几乎没有追高成本；涨跌停拦截仅 3 次，可执行性好。

反对它的（更重）：
- **样本内 -24.6%、Sharpe -0.87**。一条规则在 3.5 年里稳定亏钱、在之后 3.7 年里赚钱，最简洁的解释是风格切换，而不是稳定的因子溢价。
- **单年驱动**：2024 +33.6%，2023 -4.8%、2025 +2.9%、2026 +0.6%。去掉 2024 就没有故事了。
- **DSR 0.027**，远低于 0.95 门槛。按本轮校正，全期年化 Sharpe 要达到约 1.37（日频 0.087）才能过门槛，S07 是 0.03。
- **5 持仓无法承载 10% 分位的因子**：宇宙平均 1,429 只，10% 分位约 143 只候选，只买 5 只，组合收益主要由 5 只股票的个体波动决定（MDD -29.9%）。这不是因子检验，是抽样检验。
- 全期年化 -0.1%，**持有 7.3 年不赚钱**。

需要的下一轮验证（预注册，本轮未执行，见第 9 节）：把 2024 剔除后是否仍为正、10 持仓等权是否只改善分散化、行业/市值分解是否把收益全部归给"银行+公用事业"。

另一条更值得做的方向（不在本轮范围）：把创业板/科创板纳入宇宙后重跑 S06/S10 的截面反转 —— 现有文献的反转效应主要来自高波动小盘，本轮宇宙恰好把它们排除了。这是一个**可能被数据口径误杀**的候选，需要单独预注册。

## 11. 追加：E2 排名口径实测（2026-11-07 v1.1）

**本节不含任何收益指标、不新增因子、不重跑回测**。只做一件事：把 `caliber-decisions-20261107.md` §7.2 用「已登记选股数反算」得到的口径判断，改成对 `add_universe` 输出的**直接计数**。作废判定的依据由反算升级为实测，结论不变（S06 / S07 / S10 / S11 / S12 全部 `void`）。

方法：原样调用 `scripts/common.py` 的 `add_universe`（未改一行代码），取 3 个 S07 月末调仓日（2021-06-30 / 2024-06-28 / 2026-09-30），逐日给出 `P`（池内家数）、`count(rk ≤ t)`、比值。判据是算术恒等式：**若 `rk` 是池内分位，`count(rk ≤ t)` 必须等于 `t × P`**（average 名次法下精确相等）。

### 11.1 恒等式检验：9 格全部不通过

| 调仓日 | P（池内家数） | `rk_ret5 ≤ 0.05`（S06） | `rk_vol60 ≤ 0.10`（S07/S12） | `rk_ret20 ≤ 0.10`（S10） |
| --- | ---: | ---: | ---: | ---: |
| 2021-06-30 | 1,210 | 35 / **2.89%** | 26 / **2.15%** | 75 / **6.20%** |
| 2024-06-28 | 1,037 | 15 / **1.45%** | 56 / **5.40%** | 19 / **1.83%** |
| 2026-09-30 | 1,790 | 83 / **4.64%** | 90 / **5.03%** | 153 / **8.55%** |
| 名义阈值 | — | 5% | 10% | 10% |
| 应有计数 `t × P` | — | 60.5 / 51.9 / 89.5 | 121 / 103.7 / 179 | 121 / 103.7 / 179 |
| §7.2 反算值 | — | 3.5% | 3.9% | 6.5% |

每格格式 = `count(rk ≤ t) / 比值`（比值 = count ÷ P）。**没有一格等于名义阈值，9/9 不通过。**

### 11.2 机制：分子是全样本名次，分母是池内家数（实测确证）

| 调仓日 | P | 当日全样本非空 `vol60` 行数 | `max(rk_vol60)` | `max(rk) × P` | 池内 `rk_vol60 > 1` 的行 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2021-06-30 | 1,210 | 3,041 | 2.513 | 3,041 | 964 / 1,210（79.7%） |
| 2024-06-28 | 1,037 | 3,171 | 3.057 | 3,170 | 618 / 1,037（59.6%） |
| 2026-09-30 | 1,790 | 3,182 | 1.778 | 3,182 | 1,086 / 1,790（60.7%） |

四点读法：

1. **`rk` 可以大于 1**，实测最大 1.78–3.06。若分子是池内名次、分母是池内家数，`rk` 不可能超过 1。`max(rk) × P` 恰等于当日全样本非空行数（3,041 / 3,170 / 3,182；2024 那格差 1，是 average 名次法并列所致）—— **分子是当日全样本 3,000+ 只的名次，分母是池内 1,000–1,800 只**。
2. 这实测确证了 §7.1 对 `when/then` 不改变 `rank()` 作用域的判断，并说明**研究侧与系统侧犯的是同一个作用域错误**：系统侧 `rank / count(x)` 分母取全样本（更松，S07 选 ≈21.5% 池内），研究侧 `rank / in_universe.sum()` 分子取全样本（更紧），方向相反、错误同源。
3. 因此 `rk ≤ t` 的真实含义是「**全样本名次 ≤ t × P**」，选中集合 = 池内 ∩ 全样本最低 `t × P` 名。它必然 ≤ `t × P`，缺口来自池子漏掉全样本的低波动尾部：2021-06-30 全样本 `vol60` 最低的 121 只里只有 26 只在池内（21.5%）。
4. **这条比 §7.2 的表述更狠，方向要对准**：研究侧选出来的不是「池内波动最低 10% 的更严格子集」，而是「**全样本名次 ≤ `t×P`（2021-06-30 为 121 只，不是全样本的 10%≈310 只）与池子的交集**」—— **集合本身就不是同一个东西**。因此调阈值只改计数、不改排序依据，不能把选股集合恢复成「池内最低 10%」；S07 的「研究线索」身份不能保留。
5. `rk` 在池外恰为 `null`；三个日期上「池内家数」与「池内该列非空家数」完全相等（1,210 / 1,037 / 1,790），说明这三天错的是**分子**不是分母。§7.6 关心的「分母多算」在这三天不存在，但**不等于全样本不存在**（未确证）。

### 11.3 与已登记数字交叉核对（证明验算走的是同一条代码路径）

- 原样重跑 `add_universe` 得到的信号数：`e_lowvol` 4,883、`e_xsrev` 18,694、`e_xsrev20` 8,162、`e_lowvol_rev` 1,293 —— 与 `registry.json` 中 10bp 情景**逐位相同**。
