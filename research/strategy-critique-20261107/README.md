## 六问的写法与证据等级

每条策略按委托要求回答六问（机制是否被文献检验过 / 在指定口径下靠什么赚钱赚谁的钱 / 参数出处 / 失效条件是否可前置判定 / 真实 A 股执行是否先验吃掉 / 是否与同批换皮重复）。每个判断都标 **已确证 / 证据不足 / 未知**：

- **已确证**：可由本目录引用的项目文件直接核到（如拦截次数、跳空均值、出场构成、同笔重合）；
- **证据不足**：可核到作者·年份·标题，但结论细节未联网核对（本轮未核页码/DOI，也未做中文文献检索）；
- **未知**：我不判断，例如 A 股本土是否真的存在低波动异象、停牌计数是否有效、对手方是谁。

## 三条跨策略的发现（比单条更重要）

1. **判死线大面积失效**：12 条里 8 条的"失效条件"起不到作用——结构上不可达（S06、S10）、定义失效（S07 总收益≈0 时"单年贡献占比"无意义）、会放行负收益（S12）、与敞口不可比（S11）、混淆结构与结果（S08、S09）、纯事后（S01、S03）。
2. **出场规则多数是装饰**：S04/S05/S06/S07/S08/S10/S11/S12 的平仓有 65%–100% 由 `max_hold` 触发。所以"RSI>55 出场"、"回中轨出场"、"动量转负出场"在多数交易里没生效。任何引用这些结果的地方都应改写成"买入后固定持有 N 天"。
3. **横向比较必须先按敞口归一化**：平均敞口从 0.23（S11）到 0.58（S01/S02）。不归一化就会把"持有现金多"误读成"策略稳健"。
