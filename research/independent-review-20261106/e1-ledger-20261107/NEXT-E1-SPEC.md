# 下一版E1诊断规格建议（待独立新冻结，不改变v3）

这是审核建议，不代表新版本已经实现、冻结或通过。沿用原始E1 v3 FAIL。新版本的名称、参数、阈值、可测范围及退出码必须在执行前独立落盘；不得用本轮已知数字选取能使样本通过的阈值。一次C00诊断不能给所有策略的数据有效性背书，更不构成盈利检验。

## 1. 分开三个问题

- **样本成员敏感性**：保留A完整面板/B按终点可观察停更标签剔除整只证券的比较，明确它是事后对照，不是可用于交易的PIT成员选择。报告CAGR/逐年/风险差及符号；本次正差只表示B低估本C00收益，不能推断全市场偏差严重程度。
- **估值可信度与退出约束**：从整个持有路径计算缺行、报价陈旧、停更后被动挂账及订单阻塞的金额、持续时间与账户影响；正常、有新报价的期末未平仓仓位只作为状态，不以其全额触发异常风险门槛。
- **不可识别的数据遗漏**：权威生命周期与历史证券全集不全时，将面板外消失、退市清算、停牌与供应商断供的因果区分保留unknown。不要让前两项表现温和将该维度改成PASS。

每项分别产出 `PASS/WARN/FAIL/UNKNOWN/INPUT_ERROR` 与理由；执行成功与诊断通过分开。总报告若存在关键UNKNOWN，只能写“可测维度结果…；全局数据有效性未证实”。

## 2. 冻结输入和身份

固定数据IPC、交易日历、证券ID映射（更名/代码复用/合并）、ST、除权除息/PIT因子、所有代码与配置、进出场时序、报价有效性定义、最大估值年龄与退出阻塞阈值。加入逐日生命周期表（若存在）的as_of/有效区间/来源；不存在就用null并明确unknown，不自行用最后报价日推造退市日。

观察日历必须独立于被持有股票是否有bar；优先用权威交易所日历。若仍用面板日期并集，注明整市场缺行不可探测。未来生命周期、终点last_bar标签仅用于事后诊断，不允许进入当日信号或撮合资格。

价格身份必须明确：股份使用原始股数/复权等价股数、价格采用raw/adjusted何种基准、分红与拆并股如何同步。若没有每日仓位/公司行动账，不做精确金额损失归因。保存整体宇宙按日期的覆盖率，不能把无bar的股票从分母静默删除。

## 3. 必须持久化的路径材料

每天至少一行账户账和每个持仓lot的状态（包括缺报价日），另存订单生命周期。要求时间点能区分开盘前、成交、日终；卖出日盘中风险不能因日终仓位归零而丢失。

| 表 | 必要字段 |
| --- | --- |
| `position_marks` | date/time、account_id、lot_id、symbol、shares及变动原因、raw/adjusted basis、cash_dividends、mark、mark_source(last_close/当日有效close/entry_fallback等)、quote_date、quote_age_sessions、market_value、生命周期状态及是否unknown、missing_row/无效close/volume0标志 |
| `account_daily` | 日期、现金、逐仓市值和、权益、手续费/税/分红现金流、正常/陈旧/未知估值金额；对齐统一日历 |
| `order_attempts` | 订单/lot ID、意图生成日、可首次执行日、尝试日、成功/拒绝、原因（缺价/停牌/跌停/其他unknown）、残余数量、原始信号，直到成交/撤销/期末未决 |
| `coverage_daily` | 日期、当时可知证券全集与可报价/无报价数、生命周期源覆盖情况、面板缺口；区分not-listed与unknown |

必须覆盖carry跨折、跨年、训练失败停止段；期末未成交订单保留为右删失，不伪造终端成交。逐日 `cash + sum(market_value) == equity`，逐仓股份变化与现金流守恒；不足以对账则INPUT_ERROR或金额指标UNKNOWN。

## 4. 路径指标与分母

令V(i,t)为按固定规则标记的lot市值，E(t)为账户权益，a(i,t)为独立交易日历上距离最近有效报价的会话数。对多lot去重需有明确规则；比率金额分母为同一时点权益，时间率分母不能偷换为总证券日期行数。权益<=0或估值缺失使比例不可定义时，直接报告破产/unknown，不填0。

| 指标 | 定义与输出 |
| --- | --- |
| 缺报价/陈旧日暴露 | `X_missing(t)=sum(V*missing_row)/E(t)`；按预冻结年龄k计算`X_age_k(t)=sum(V*(a>=k))/E(t)`，同时提供k=1/5/20等预设诊断档。报告max、日期、时间加权均值、p95、非零天数及最长连续段。k不可根据结果择优。缺行不等于退市。 |
| 未知估值暴露 | mark_source=entry_fallback或quote_date未知的金额占比与天数单列；不能设a=0。金额本身不可知时同时报冻结最后账面额和“金额不可确定”，不作零风险。 |
| 缺报价持仓会话率 | 缺报价position-session/全部持仓position-session；另报存在异常的账户日/全部账户日。原始计数和分母一同保存。仅作频度指标，不替代金额权重。 |
| 停更后/恢复前暴露 | 按当时已观察到的报价缺口测量整个区间；终点S_stale成员的历史持仓额另列为ex-post成员敏感性，不能把成员上市期间全部持仓都标为停更风险。 |
| 退出阻塞 | 每个真实退出意图首次可执行日至实际成交/期末的等待交易日，失败原因与可卖残余市值；报告总/最长/分位数、被阻塞lot比例、峰值金额、期末右删失。T+1、法定非交易日、信号尚未生效分开，不算数据缺陷。无退出意图时只能说“有潜在约束代理”，不能捏造实际失败卖单。 |
| 流动性代理 | 日线volume=0、open无效、跌停等按固定规则分类；有正volume/open不能证明排队可成交，实际盘中成交能力仍unknown。 |
| 终点分解 | 正常新报价、年龄>0、终点停更集合、估值未知及未决退出仓位分别报告（可重叠标签，合计需额外互斥分类）。正常终点仓位不自动失败，停更为0不使路径风险消失。 |

本轮只能观测区间代理：两组各1缺行会话、各3延期退出日；没有以上每日原始账，不能声称完整算出金额路径。下一版不可直接将本轮代理作为完整路径验收结果。

## 5. 压力诊断

保留终点haircut为一个次要指标，新增对**实际已持有且进入报价缺口/不可退出状态**的路径压力。预设0/30/50/100%损失率可作敏感性轴，作用到具体lot/日期且只计一次，避免同一缺口日复利重复扣减。正常新报价仓位不被统一视为坏账。

每一压力模型须说明是“账面重估压力”（不改交易决策）还是“重新回放账户”（会改变现金、后续下单和持仓）；前者不能称为可实现的反事实收益。记录缺口起点、恢复、右删失与回收率假设；没有权威生命周期时不宣称模拟了真实退市清算。压力损失带来的最大权益差/最大回撤差、恢复时间和终值影响一同报告，不能只报CAGR。数据情景间不择优候选；若用于选择，应另记选择事件。

## 6. 判定与验证器要求

先冻结每一风险预算的经济对象与分母。若保留2%预算，应明确它究竟约束“最大陈旧/不可估值暴露”还是“压力损失占权益”，不是无条件套在全部未平仓仓位上；2%本身缺少经验证据，本建议不替其背书。允许先作为描述性诊断并将总体结论UNKNOWN，不必为了产生PASS创造阈值。

验证器必须从原始账重算，而非相信结果JSON中的checks=true。增加无需alpha搜索的受控反例：正常期末仓位50%且报价新鲜；持仓中途缺报后恢复且终点仓位0；未来退市标签但当前正常成交；延迟退出跨年carry且终点已清仓；期末未决卖单；缺行但未知生命周期；公司行动改变股数；全日历缺失；缺少路径表；两条规则同名不同参数。前两例分别应证明“正常仓位不冒充陈旧风险”和“终点为零不掩盖历史风险”。缺失输入必须得UNKNOWN/INPUT_ERROR，不能空集合全true。

本轮不实施上述新回放。新规格与阈值先冻结，再由研究和开发各自负责产物生成与研究验收，审核基于原始逐日材料复核；旧v3输出保持原样。

## 7. 账本后续字段

每个假设用稳定ID和parent_id，保存完整信号/参数（含默认值）、宇宙、交易与成本口径、代码与数据版本指纹、创建时间与预期用途。每次执行另存execution_id、fold/样本/成本轴、是否复现、状态、结果位置；每次基于结果作选择另存selection_id、候选集合、所见数据、决定与新增计数理由。

把“不同规则形式数”“执行次数”“选择机会数”“DSR有效独立N”分列。当前最少17规则形式与96条所选执行记录不能覆盖全部历史；未登记历史、版本修订和情景择优保留unknown。不得用相关性主观降N，亦不得机械把折次数加进独立假设数。下一版账本应引用本次清单及原始证据，但不能修改旧冻结记录来伪造其运行前已经完整登记。
