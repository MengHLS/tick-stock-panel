# 新能源产业链图谱研究

研究日期：2026-11-04。用途：为本地产业链脑图整理分类和股票关联口径。下文先给出研究建议，当前已按该结构落地到本地图谱；运行数据仍以图谱 API 为准。本文件不涉及投资排序和收益预测。

## 结论与范围

建议沿用“新能源”入口，展开光伏、风电、电池与材料、储能系统、氢能五条主要研究链；另设“电网与充换电（配套）”研究链。这是一种面向股票研究的导航分类，不是对官方行业分类的照搬，也不表示电网、储能、电池均为一次能源。

若未来需要纳入核电、大水电等更广的低碳能源，可另建“能源与电力”入口。当前建议先完成上述核心范围，光热、生物质、地热等可再生能源另列后续补充，不把六条分支称作全部新能源。

按资料反映的实际产品和价值链拆分各条链，不统一套用“基础层—平台层—应用层”。脑图只展示产业环节和产品，股票沿用现有右侧列表。

## 1. 光伏

建议结构：

- 主材制造：多晶硅 → 硅棒/硅锭与硅片 → 电池片 → 组件。
- 辅材：玻璃、封装胶膜、背板、边框等。
- 制造装备：拉晶/切片、电池片工艺、组件封装与检测装备。
- 电站设备：光伏逆变器、支架、汇流与电气连接。
- 建设运营：电站开发、EPC、运维与回收。

这里的箭头是生产关系，实际导航可把各制造环节作为同级子节点，避免把“下游”误表示成“属于上游的子类”。工信部材料将多晶硅、硅棒、硅锭、硅片、电池、组件、逆变器列入光伏制造范围。[S1] 隆基披露的组件辅材包括光伏玻璃、EVA/POE胶膜、铝边框、背板。[S2]

TOPCon、HJT、BC等应细分在电池片技术下；不能和“硅料”“组件”“光伏设备”放在同一逻辑层级。工信部解读区分N型电池、组件并涉及TOPCon，隆基也披露BC组件业务；具体技术节点的企业关联仍须逐家核验。[S3][S4]

## 2. 风电

建议结构：

- 材料与部件：叶片与复合材料、轴承/主轴/齿轮箱、发电机/变流器/控制系统。
- 塔架与基础：塔筒、基础结构；海上场景继续细分海上基础、海缆等。
- 整机制造：陆上风机、海上风机。
- 工程交付：运输、吊装、海上施工与并网。
- 运营服务：风场运营、监测运维、技改和退役回收。

金风科技产品手册列有叶片、变桨、轮毂、轴系、齿轮箱、发电机、偏航、控制及电源等部件，并区分陆上、海上风机。[S5] 其运维服务覆盖备件、维修、软件升级、技改和发电量提升；可持续发展报告还涉及塔筒、电缆、箱变和叶片等回收处理。[S6][S7]

海上/陆上是产品和应用场景差异；叶片/轴承是部件类别。建议在整机下细分海陆场景，在部件下按产品分类，不复制整套海陆上下游。

## 3. 电池与材料

范围以动力、储能等可充电电池的制造为主，燃料电池归氢能链研究。

建议结构：

- 资源与加工：锂等资源及相应加工产品；是否加入镍、钴、锰、磷等节点取决于核实到的具体材料路线。
- 关键材料：正极、负极、隔膜、电解液、集流体与结构件。
- 制造装备：前段电极制造、中段电芯装配、后段化成检测。
- 电芯与电池系统：动力电池、储能电池及PACK/管理系统。
- 回收利用：回收、材料再生、适用条件下的梯次利用。

工信部锂离子电池规范区分消费型、动力型、储能型电池，并分别涉及电极涂覆、卷绕/叠片、注液、电池组和正负极材料等能力。[S8] 新型储能制造业行动方案则覆盖锂电、钠电、液流电池等多条技术路线及回收利用。[S9]

动力/储能是用途；锂/钠是化学体系；液态/固态是电解质形态，不能把三个分类轴简单当作互斥同级节点。沿用现有用途导航时，固态等可作为单独的技术专题，但要说明其交叉属性。

## 4. 储能系统

建议结构：

- 储能本体：电池储能、压缩空气、飞轮等；抽水蓄能在广义储能下另列。
- 系统设备：PCS、电池管理BMS、能量管理EMS、温控与消防。
- 系统集成：储能柜/预制舱、系统集成、工程建设与运维。
- 应用场景：电源侧、电网侧、用户侧。

工信部行动方案区分储能本体技术和高效集成、智慧调控，并覆盖变流器、电池管理、热管理、能量管理等。[S9] 阳光电源的系统资料列明PCS、锂离子电池和EMS等组成，提供户用、工商业和电网侧方案。[S10]

电池制造和储能系统保留独立研究视角：前者关注电芯、材料与制造，后者关注整套系统和运营。同一股票可以出现在两条链中，每条关联要分别说明实际业务。

若分支名使用“新型储能”，不能将抽水蓄能放入其中：国家能源局对新型储能的定义明确排除抽水蓄能。[S11] “长时储能”是时间特征，不与液流、压缩空气等技术路线当作互斥分类。

## 5. 氢能

建议按制氢、储运、加注、应用梳理，设备及关键材料放在对应环节。可再生能源制氢与化石能源制氢需要明确区分；不能因为公司存在制氢业务就认定属于绿氢。

## 6. 电网与充换电（配套）

建议分为输变电、配电、调度与能源服务、充换电四组。电网是能源输送和消纳的系统配套，充换电是电动交通补能设施；两者均不应挂到光伏或动力电池的下一级作为其组成产品。新能源汽车整车保留为下游应用或独立汽车链入口。

氢能与配套设施的具体官方来源、分类边界见同次研究材料 `.artifacts/new-energy-boundaries-20261104.md`。这些是导航建议，仍需在实施前按来源补齐具体产品和股票映射。

## 与当前系统的衔接建议

实施前运行图谱只有一条新能源相关产业链 `power-battery`，名称为“动力电池”，共14个节点，已包含储能电池、储能系统、锂资源、固态电池、固态电池材料。

建议后续实施：

1. 展示名改为“新能源产业链”，保留原产业链ID，避免打断历史关联；原电池节点统一挂到“电池与材料”分支。
2. 新增光伏、风电、储能系统、氢能和配套设施研究链。
3. 保留现有所有股票理由、来源和核验状态。新增关联按“节点+股票”判重；跨链可以独立关联。
4. 现有“储能电池”保留在电池制造视角；“储能系统”节点在新增链形成后再迁移或明确为下游入口，迁移必须带上原有股票关联。
5. 股票理由描述产品或业务，例如“提供储能变流器及系统”“生产单晶硅片”，不以“新能源概念”替代证据。
6. 历史涨停题材仅作为线索：具体记录、日期和题材保留在备注，不能因本次归类自动升级为已核验。
7. 分类数据完善即可复用现有扩展图谱API、搜索、侧栏和分析功能；无需为新能源另写页面或数据接口。当前单父节点模型不表达真实的多对多产业关系，先以独立股票关联实现跨链研究，避免把跨链供需关系伪装为父子归属。

### 已实施结果（2026-11-04）

- 顶层分支：光伏、风电、电池与材料、储能系统、氢能、电网与充换电（配套）。
- 新能源链共 83 个节点、1,189 条股票关联、739 只去重股票；同一股票可在不同环节独立关联，理由分别填写。
- 原有 130 条电池关联及其理由、来源、核验状态均保留；仅将三个原顶层节点挂到“电池与材料”之下。
- 涨停题材窗口已回溯到 `2025-10-16..2026-11-04`；新能源链累计 1,189 条关联，较回溯前新增 849 条“待核验”线索。记录保留日期、来源和原始题材，不把历史涨停题材升级为已核验业务事实。
- 新增结构化题材映射覆盖多晶硅、硅片、电池片、组件、光伏玻璃、胶膜、支架、逆变器、风电叶片/齿轮箱/轴承、海缆、塔筒、储能 PCS/BMS/温控、液流/钠电/压缩空气、电解槽/储氢瓶/加氢站、特高压/变压器/充电桩/换电等具体环节；宽泛的“光伏、风电、储能、氢能、新能源”不自动归入末级节点。
- 页面层继续复用现有脑图、搜索和右侧股票列表；点击末级节点打开列表，切换节点不改变画布缩放。
