## 1. 为什么换一种记法差 5.4 倍：一个精确恒等式

199 臂三个数互不相等，原因是它们各自只覆盖了损益的一部分：

| 量 | 数值 | 覆盖范围 |
|---|---:|---|
| `Σ pnl_amount` | 326,858.21 | 已平仓 194 笔，含现金分红；期末 5 笔记 0 |
| `Σ (exit_value − entry_value)` | 216,112.70 | 全部 199 笔的价格变动；不含分红；期末 5 笔按市价 |
| 权益变动（`final_equity − 1,000,000`） | 242,725.28 | 已实现 + 未实现，即经济真值 |

恒等式（残差 0.02 元）：

```
Σpnl_amount − Σ(期末 5 笔市值变动) = 326,858.21 − (−84,132.95) = 242,725.26 ≈ 242,725.28
Σpnl_amount − Σ价差                 = 326,858.21 − 216,112.70 = 110,745.51
其中  现金分红 24 笔                = +26,612.57
      期末未平仓 5 笔（pnl 记 0）    = +84,132.95
```

同理，208 臂 `pnl_amount` 与价差法逐笔相等（208/208，合计差 0.10），因为该臂价基为复权价，分红已在价格里，无需另记。

**所以两种记法不是"算错了"，而是回答两个不同的问题**：`pnl_amount` 答"已实现损益（含分红）"，价差法答"持有期价格变动（含未实现、不含分红）"。拿其中任一个去度量"同一批交易的重新定价"都会带上系统性偏差。

### 1.1 三法的差可以逐项对上（同键 111 笔内）

同键（`(symbol, entry_date)` 唯一：208/208、199/199，无重复键，故匹配 111 笔干净）：

| 成分 | 金额 | 归属 |
|---|---:|---|
| 权益锚定差（正确口径） | **+32,481.24** | 199 臂 − 208 臂，同键 |
| ＋ 4 笔期末未平仓 `pnl_amount=0` 的记账效应 | +70,199.96 | 仅 `pnl_amount` 法有 |
| ＝ `pnl_amount` 法同键差 | +102,681.20 | 12.18% |
| － 同键内被价差法漏计的现金分红 | −13,352.72 | 仅价差法缺 |
| ＝ 价差法同键差 | +19,128.46 | 2.61% |

三法同键差 **32,481.24 / 102,681.20 / 19,128.46**，两条偏差在**金额上**精确闭合：`102,681.20 − 32,481.24 = 70,199.96`、`32,481.24 − 19,128.46 = 13,352.72`。百分比不可直接相加减，因为三法的分母不同（843,286.99 / 732,541.58 / 759,154.04）。

## 3. 给策略经理：可直接进口径文档的替换句

> 该 75.74pp 中，同一批交易（`(symbol, entry_date)` 键 111 笔）的重新定价占 **4.28%**（32,481.24 / 759,154.04 元，以权益变动为锚），其余 **95.72%** 来自成交集合本身不同（208 笔 vs 199 笔）。单一记法会失真：`pnl_amount` 记法得 12.18%（其中 70,199.96 元来自 4 笔期末未平仓被记 0 损益），`exit_value−entry_value` 记法得 2.61%（漏计现金分红 13,352.72 元）。两项偏差已逐笔归因到分，非随机、非记账错误；定性结论不随记法改变。

若篇幅只允许一句：

> 同一批交易的重新定价占 4.28%（权益锚定口径；换 `pnl_amount` 记法为 12.18%、价差法为 2.61%，偏差均可逐笔归因），其余 ≥95.7% 来自成交集合不同。

同时请把此前「87.8% 来自成交集合改变」改为 **「≥87.8%（三法 87.8% / 95.7% / 97.4%）」**，原句在价差法下会被读成高估（实际 97.4%）。

## 4. 对 ⑤-a 的报数要求（维持并加严）

每臂除笔数 / 收益 / MDD / Sharpe / `buy_limit_up` 外，必须同时报：

1. 与 a0 的同键笔数，以及**同键 / 仅本臂**的两种记法拆分（`Σpnl_amount` 与 `Σ(exit−entry)`），并附**第三种：权益锚定拆分**（期末未平仓用价差、平仓用 `pnl_amount`）。
2. `open_at_end_count` 与其市值合计 —— 否则单臂若含期末未平仓，`pnl_amount` 记法会系统性压低该臂同键差（本例 4 笔即 70,199.96 元，占该法同键差的 68%）。
3. 每臂 `Σpnl_amount + 未实现 − 权益变动` 的对账残差（本例 199 臂 0.02 元；208 臂 1,722.56 元，见 §5）。

单记法占比不再进入任何对外结论。

## 6. 复跑

所有数字均可在 DuckDB 里对下列文件直接复算（路径相对本目录）：

```sql
-- 三法合计
SELECT 'a0' arm, count(*), sum(pnl_amount), sum(exit_value-entry_value) FROM 'results/a0_10bp/trades.parquet'
UNION ALL
SELECT 'c0', count(*), sum(pnl_amount), sum(exit_value-entry_value) FROM 'results/c0_10bp/trades.parquet';

-- 同键 111 笔的三法差
WITH j AS (
  SELECT a.pnl_amount pa, b.pnl_amount pb, b.open_at_end boe,
         a.exit_value-a.entry_value da, b.exit_value-b.entry_value db
  FROM 'results/a0_10bp/trades.parquet' a
  JOIN 'results/c0_10bp/trades.parquet' b USING (symbol, entry_date))
SELECT count(*), sum(pb-pa) d_pnl, sum(db-da) d_pd,
       sum(CASE WHEN boe THEN db ELSE pb END - pa) d_econ FROM j;

-- 29 笔不符
SELECT symbol, entry_date, exit_date, shares, open_at_end,
       pnl_amount-(exit_value-entry_value) gap
FROM 'results/c0_10bp/trades.parquet'
WHERE abs(pnl_amount-(exit_value-entry_value))>0.011 ORDER BY gap DESC;

-- 每笔记账缺口 vs 除权表
SELECT t.symbol, t.entry_date, sum(e.dividend) div, sum(e.bonus) bonus,
       sum(e.dividend)*t.shares/(1+sum(e.bonus)) AS div_x_preshares,
       t.pnl_amount-(t.exit_value-t.entry_value) gap
FROM 'results/c0_10bp/trades.parquet' t
JOIN 'D:/TSP/data/adj_factor/all.parquet' e
  ON e.symbol=t.symbol AND e.trade_date>t.entry_date::DATE AND e.trade_date<=t.exit_date::DATE
WHERE abs(t.pnl_amount-(t.exit_value-t.entry_value))>0.011 GROUP BY ALL;
```
