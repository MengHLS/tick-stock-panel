# ⑤-a 追加 · 两种记法并报 + 199 注入臂 29 笔「两法不等」裁定

口径：基线 = `base_nodefaults_10bp`（不注入任何 defaults = 生产文件真实默认，208 笔）；key = `(symbol, entry_date)`。本文件由 `gen_addendum.py` 从 `dual_accounting.json` 与 `appendix_199_29rows_classified.csv` 机读生成，不手抄数字。

## 0 · 一句话裁定

**H1（`pnl_amount` 走了与 `entry_price`/`exit_price` 不同的价基）不成立。** 29 笔的不等全部落在两种「构成差」上，且逐笔闭合：5 笔期末未平仓（`pnl_amount` 只记已实现=0，价差法取了 `end` 行的盯市价）+ 24 笔已平仓（`pnl_amount` 含持仓期现金分红/送股，价差法不含）。已平仓 24 笔用除权台账闭式预测分红 26,612.57 元，实测缺口 26,612.60 元，残差 +0.03 元，单笔最大 |残差| 0.01 元。

⇒ 不必把 `pnl_amount` 标成「跨除权笔混合口径」；要标死的是**价差法**：`exit_value − entry_value` 不含分红/送股现金，却含期末未平仓的 `end` 盯市。单用价差法做跨除权汇总会少算分红、多算期末浮亏。

代码层同样对得上（`backend/app/backtest/engine.py`，只读未改）：组合口径出场 `pnl_amount = exit_value + pos["cash_dividends"] − entry_value`（:3201-3205）；期末未平仓行 `pnl_amount = 0.0`（:4428，同行 `exit_value = shares * exit_price`、`open_at_end = True`、`exit_reason = "end"`）。即价基只一套，分红与期末盯市是另加的项。

## 4 · 为什么两法算出的「同键重定价占比」差 7 倍

同键重定价差额：A 102,681.20、B 19,128.46，差 83,552.74。该差额 == 同键对上 Σ(`pnl_amount` − 价差) 83,552.79 − 基线自身取整缺口 +0.05。即**缺口集中落在同键对上的跨除权笔**：同键对贡献了总缺口 110,745.51 的 75.4%。所以占比差 7 倍不是两把尺子量了不同的东西，而是同一批跨除权笔在 A 里被算进重定价、在 B 里被丢掉。

## 5 · 顺带查到的要紧事：「同键」不等于「同一仓位」

同键 111 笔里（199 臂 vs 208 基线，同一 `(symbol, entry_date)`）：

| 项 | 实测 |
|---|---|
| shares 不同 | 105 / 111 |
| entry_price 不同 | 111 / 111 |
| exit_price 不同 | 111 / 111 |
| 其中「同一天出场、exit_price 仍不同」 | 110 / 110 |
| exit_date 不同 | 1 / 111 |
| duration 不同 | 5 / 111 |
| shares 比值（99/08）中位 / 最小 / 最大 | 1.0758 / 0.2222 / 3.0337 |
| 仓位金额占比中位（99 / 08） | 11.80% / 11.87% |

仓位金额接近（11.80% vs 11.87%）而 shares 比值横跨 0.22–3.03；更决定性的是：110 笔当天出场的那批里 110 笔 exit_price 仍不同——同一天、同一只股的成交价没理由变，除非两臂的**价格列本身不在同一基上**。

**机制已在代码里坐实**（`backend/app/backtest/engine.py`，只读未改）：除权台账只在 raw 价执行时加载——`corporate_actions = self._load_corporate_actions(...) if raw_execution is not None else {}`（:2608-2615）；加载后逐日对持仓做送股/转增 `shares *= share_multiplier`、`entry_price` 按除权重算（:3823-3830），现金分红 `pos["cash_dividends"] += dividend_per_share × old_shares` 并同时进 `cash`（:3817-3822）。所以：默认（208）口径走复权价、除权台账为空 ⇒ 分红与送股全含在价格里，`pnl` 恒等于价差；199 注入臂走 raw 价 + 除权台账 ⇒ 股数被送股放大、分红落成现金并回加进 `pnl`。

⇒「同键重定价」实际上是「同键、不同价基（复权 vs raw + 除权台账）、不同股数」，**不能读成「同一仓位换了价格」**；任何把同键 Δ 解释成纯价格效应的说法都不成立。

## 6 · 使用说明（建议原样写进任何引用这两列的地方）

1. `pnl_amount` = **已实现**损益：含持仓期现金分红与送股现金，**不含**期末未平仓的浮盈浮亏（该分支恒 0）。
2. `exit_value − entry_value` = **含期末盯市**的价差：**不含**分红/送股现金，但把 `end` 行的盯市价算进去。
3. 两法差额 = 分红现金（已平仓）+ 期末盯市（未平仓）。默认（208）口径下两法在 208/208 笔上相等（合计差 0.10 元），**只在注入 `entry_price_basis=raw` 一类改动的臂上才会分开**——所以引用占比时必须写明是哪一臂、哪一种记法。
4. 跨除权笔的「按笔汇总」优先用 `pnl_amount`；用价差法则必须另加分红现金，否则系统性地少算。
