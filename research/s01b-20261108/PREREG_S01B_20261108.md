## F1（成本敏感性）
原文：10bp 全期年化为负且 30bp 更负 → 无效，不得再调出场参数继续搜。
判定口径：`annual_return`（全期 2019-07-01..2026-10-30，StrategyBacktestService 口径）。
10bp 与 30bp 分别取 `results/<arm>_10bp/result.json:stats.annual_return` 与
`results/<arm>_30bp/...`。仅当 arm_10bp < 0 且 arm_30bp < arm_10bp 才成立。

## F2（入场 alpha）
原文：gross 全期年化仍为负 → 入场无 alpha，停止在该入场上调出场。
判定口径：`--gross`（佣金/印花/过户/滑点全部归零）同一区间的 `annual_return` < 0。

## F3（改进来源）
原文：亏损减少全来自换手/暴露下降而非单笔改善 → 不算改进。
判定口径：逐笔平均收益 `avg_pnl`（stats，含未平仓不计）与入场笔数、年换手
（Σ entry_value / 1,000,000 / 年数）、平均暴露 `avg_exposure` 同时比较。
「单笔改善」= 相对臂 0，`avg_pnl` 上升且 `median_pnl` 上升；
「换手/暴露下降」= 年换手下降或 `avg_exposure` 下降。
若 avg_pnl 与 median_pnl 均未上升，而年换手或 avg_exposure 下降 → F3 成立（不算改进）。

## F4（止损是否噪声收割）
原文：臂 1 的 OOS 比基线更差且换手 > 1.5× → 止损是噪声收割机，退回只做 45 天上限。

OOS 的算法一致：段首权益 = 2022-12-30 权益）。换手比 = 臂 1 年换手 / 臂 0 年换手。
两条同时满足才成立。
