## 1. C1 量能门：`vol_ratio_10d(t) ≥ 1.5`

### 1.1 理由来源属哪一类

**主类别：公开常识／行业惯例（量价确认）＋ 机制推理（参与度）。** 次类别：文献（**未核原文，只作类别标注，不作证据**）。

### 1.2 具体推理链（三步，不引用任何本池读数）

1. **金叉本身不是「有资金参与」的证据。** `MA20 上穿 MA60` 只描述两条收盘均线的相对位置变化，输入只有收盘价。下跌趋势末端的无量反抽、横盘末端的窄幅抖动，都能让 MA20 越过 MA60。价位条件对「有没有换手承接」是盲的。
2. **量能是价位之外唯一同日可得、且与「承接」直接挂钩的量。** 把 t 日成交量与**该股自己的近 10 日均量**比（而不是与全市场比），消掉了市值、板块活跃度、个股流动性这些跨截面混杂，只保留「这只股票今天相对它平常放大了多少」这一个维度。
3. **1.5 的语义是「明显放量而非日常波动」**：以自身近 10 日均量为基准，放大 50% 属需要额外买卖盘才能形成的量级；倍数取 1.5 而非 2 或 3，是这条惯例里最常用的分档（行业上「量比 > 1.5」被当作放量的粗分界）。**这是一个约定常数，不是从任何收益分布反解出来的数**；它在本项目中也早于本轮存在（`S09` 同用 1.5，见 §4.2）。
4. **可证伪形态**：若 C1 臂 `T < T₀`（预注册 G1），则「放量能把有承接的转向与无量反抽分开」在本池不成立，门关闭（预注册 §1.1 已写死同一证伪条件，我认可）。

### 1.3 本条理由是否用到了这 199 笔的回吐或盈亏分布

**没有。** 三处逐项交代：

| 环节 | 是否用到 199 笔分布 | 说明 |
|---|---|---|
| 条件形状（量比 > 阈值） | 否 | 形状来自「价位条件对参与度是盲的」这条机制缺口，在拿到任何本池读数之前即可提出 |
| 阈值数值 1.5 | 否 | 取行业惯例分档；同为 1.5 的常数在本项目 `S09` 里已存在（早于本轮，见 §4.2），故也不可能由本轮 199 笔反解 |
| 窗口 10 日 | 否 | 交易日两周，是「近期常态量」的最短可用基线；**与均线参数 20/60 无关，不是从回吐分布里挑的** |

### 1.4 先验强度自评：**弱—中等**

诚实说明两条会削弱先验的事实（**只作强度说明，不改条件、不改阈值**）：

- **量价确认在学术上的证据并不强**，且方向不一致：成交量与后续收益的关系在不同市场、不同频率上反复出现符号翻转。本条我**不主张文献支持**（本次未核任何原文），只主张「这是行业惯例 + 有机制解释」。
- **同思想的独立入场在本池是深度负的**（§3 必披露事实一），这使「放量能筛选」在**本池**的合理性存疑。

### 1.5 语义精确定义（因子口径，供实现与 ⑥C 逐笔核对）

| 项 | 定义 |
|---|---|
| 因子 id | `vol_ratio_10d`（已注册：`backend/app/factors/registry.py:147-151`，`_virtual`，deps `{volume}`，`warmup_bars=11`） |
| 实现 | `backend/app/backtest/matrix.py:4307-4316`：`previous_volume = valid_shift(volume, 1)` → `valid_rolling_mean(previous_volume, …, 10)` → `_matrix_ratio(volume, previous_mean)` |
| 分子 | **t 日**成交量 |
| 分母 | **前 10 个有效 bar**（不含当日）的成交量算术均值 |

| 比较 | `≥ 1.5`（**含等号**，冻结） |
| 复权口径 | **比值无量纲，任何逐日常数缩放相消**；价格侧用前复权 `close`、与本门无关。**一处待核**：若数据源在送转/拆股日对 `volume` 做了几何调整（而价格用前复权），跨越除权日的 10 日窗口可能出现机械跳变——本会话**未核到 `volume` 的复权处理代码路径**，列为 §6 待核项 1（不影响条件与阈值，属覆盖度/口径证据） |
| 无前视 | 分子分母在 t 日**收盘后**全部可得；成交在 t+1 开盘（`matching="open_t+1"`），门与金叉同时点 |

## 2. C2 趋势门：`ma60(t) > ma60(t − 20)`

### 2.1 理由来源属哪一类

**主类别：风控惯例（不在中期均线下行时开仓）＋ 机制推理（均线方向 = 中期成本重心移动方向）。** 辅助：日历常量（20 交易日 ≈ 一个月）。次类别：文献（趋势/时序动量的符号效应，**未核原文，只作类别标注**）。

### 2.2 具体推理链（三步，不引用任何本池读数）

1. **金叉的两个输入都是短期与中期均线的交点，交点不约束中期均线自身的斜率。** MA60 仍在下行时，MA20 的一次反弹就能制造出「上穿」。这类交叉在趋势下行段里会反复出现，且每次出现时的中期成本重心都在下移。
2. **MA60 的斜率符号是「中期成本重心在往哪走」的直接测量。** 60 个交易日的均值窗口覆盖约一个季度，其 20 交易日差分（≈一个月）测的是**方向**而不是幅度。要求它严格为正（`>`）等价于要求「中期持仓者整体尚未浮亏加重」这个必要条件成立，才允许在 MA20/60 交叉处开仓。
3. **20 的取法来自日历常量，不来自数据。** 20 个交易日 ≈ 一个自然月，是本项目与行业里通用的「月」窗口（`ma20` 本身即「月线」）；它与入场规则里的 `fast_period=20` 是同一个惯例常数，**不是为这条门单独挑的**。
4. **本门的关键抗过拟合性质（我主张的、可核的）**：**这是一道符号门，没有可调的幅度参数**。阈值不是 0.05 也不是 3%，只要 `>`；自由数字只有回看长度 20，而它由日历常量给定。相对 C1（数值阈值 1.5 可滑动），C2 在参数维度上更「薄」。
5. **可证伪形态**：若 C2 臂 `T < T₀`，则「中期均线方向可作入场闸」在本池不成立，门关闭（同预注册 §1.1）。

### 2.3 本条理由是否用到了这 199 笔的回吐或盈亏分布

**没有。**

| 环节 | 是否用到 199 笔分布 | 说明 |
|---|---|---|
| 条件形状（ma60 斜率符号） | 否 | 「均线下行不买」是趋势跟踪的通用前置条件，与持仓盈亏无关 |
| 比较符 `>`（严格） | 否 | 平坦即不通过，属保守侧默认；若取 `≥` 则对恰好持平的少数行放行，会引入数值噪声判定——取 `>` 是 fail-closed 的自然选择 |
| 回看 20 | 否 | 交易日×月的日历常量；与入场 `fast_period=20` 同源 |

### 2.4 先验强度自评：**中等偏弱**

- 机制上比 C1 干净（符号门、无幅度阈值），但**同族思想在本池已有深度负读数**（`S03_tsmom_60_m` −56.06%，§3）。
- 另有一条**必须写明但不能用**的判别边界（S01c D3 教训的直接延续）：**不得用任何涨跌停幅度算术为 C2 背书**。C2 不涉及出场，也不涉及 25%，本轮没有复用该论证的理由；此处声明是为了防止下游误抄。

### 2.5 语义精确定义（因子口径）

| 项 | 定义 |
|---|---|
| 左值 `ma60(t)` | 60 个**有效 bar** 的前复权收盘均值；`matrix.py:4293`（`valid_rolling_mean(close, close_valid, 60)`），支持性判定 `:4220`；满窗要求同上（不足 60 个有效观测 = NaN） |
| 右值 `ma60(t−20)` | 对 `ma60` 施加 `valid_shift(…, 20)`（`matrix.py:3300`）⇒ **该股第 n−20 根有效 bar 上的 ma60**，不是 20 个日历日前的 ma60 |
| 是否含当日 | 两级都含「其对应 bar 当日」：`ma60(t)` 含 t 日收盘；`ma60(t−20)` 含 t−20 日收盘。**无前视**：两者在 t 日收盘后均可得 |
| 比较 | `>`（**严格大于**，冻结）；两侧任一 NaN ⇒ 不通过（fail-closed） |
| 复权口径 | **前复权 `close`**（与生产文件 MA20/60 同一价基）；不复权 `raw_close` 只用于涨跌停与池价格门槛，本门不用 |
| 预热硬约束 | 需 80 根 bar 才能算出 `ma60(t−20)`；预注册 §1.3 第 4 条把 `entry_gate=2` 的 `required_warmup_bars` 抬到 81，我认可——**这是口径修正（保证窗口首日可计算），不是策略参数**，已在 §5.3 `not_counted` 明列 |
| 因子化占位（**本轮不做**） | 若日后要注册，命名建议 **`ma60_slope_20`**（`ma60 / ma60.shift(20) − 1`，符号即门），原因：`S13` 这个号段在 `docs/architecture/AUDIT_R2_20261107.md` §D.5 已被「alias 闸门」占用为**文档条目号**，因子名不宜再借 `S13` 前缀，避免二次撞语义。**我不注册、不写代码。** |

### 5.2 一处口径分歧（我给默认值，你一句话可覆盖）
