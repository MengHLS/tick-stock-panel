## 目标与交付边界

总体目标是建立可追溯的本地量化研究工作台：数据获取与质量 → 指标和策略规格 → 筛选/因子研究 → 回测与样本外验证 → 研究展示 → 监控/模拟执行 → 复盘核对。每一环节应能说明输入版本、执行口径、失败状态及证据来源。威科夫日线研究是其中一个增量项目，不代表系统全部范围。

用户于 2026-11-06 增加的主线目标：**在系统内实现各种公开策略，并持续迭代，直到找到一个样本外稳定盈利的策略**。该目标作为 S 线纳入本规划，与既有的 G 线（研究/工程能力与验收）并行推进；S 线不得绕过 G 线门槛，G 线也不得因 S 线的搜索压力而放宽验收。

本轮实际交付只包含总体规划、阶段交付清单、风险依赖登记和取证记录。后续实现任务按阶段门槛另行交给对应角色；本规划不派生交易、采购、提交、部署或重启授权。不设无依据的日历日期或工期。

## 策略搜索主线（S 线）

### 用户目标与不做承诺

目标是流程目标，不是收益承诺：把公开策略工程化、按统一口径批量评估、用可审计的登记册管理试验、在未被人看过的数据上判定，直到某个候选**通过**判定标准，或直到证据表明该路线在当前数据与成本下不成立。两种结局都是有效交付；后者必须以负结果和停止理由收口，不得用降低标准的方式得到「成功」。

明确不做承诺的部分：不承诺一定找到稳定盈利策略；不承诺达成的日历日期；不把历史回测收益表述为未来收益；不把「实现了很多策略」「跑了很多试验」当作目标达成的证据。

### 阶段顺序

严格按 S1→S6 顺序，前序未达门槛不启动后序。S1、S2 可与 G 线的修复并行准备，但任何绩效结论必须等 S1 依赖的回测路径可信（G1-04）。

### 「稳定盈利」判定口径（用户已确认，作为准入条件）

以下为规划方提出、并由用户于 2026-11-06 确认的**判定框架**，用于把「稳定盈利」变成可审查的条件。用户确认的是目标口径与用途，不是任何策略结论；阈值数值仍属研究参数，由量化研究员定稿、独立审核复核，规划方不裁定数值。

用户确认的三条约束，自本版起写入 S5 门槛：

1. **口径保留**：样本外 ≥ 1 个完整年度 + 一次性锁箱 ≥ 60 交易日；账户最大回撤 ≤ 20%；多重检验校正门槛保留（BH-FDR q < 0.1 或 DSR ≥ 0.95）。
2. **定性**：这些是**候选进入下一阶段的准入条件**，不是盈利承诺，也不是对未来的收益预期。
3. **降级规则**：任何未通过锁箱的多重检验校正结果，一律降级为**探索性结论**，不得写入推荐候选，不得表述为「已找到稳定盈利策略」。

| 维度 | 建议判定 | 设立理由 | 阈值归属 |
| --- | --- | --- | --- |
| 样本外长度 | 完全未参与选择/调参/事件修正的样本外 ≥ 1 个完整年度（≥240 交易日）；另设一次性锁箱 ≥ 60 交易日，仅在 S5 开封 | 同一段历史被反复试验后不再是样本外；锁箱是唯一能对抗搜索污染的证据 | 用户已确认 ≥240/≥60 口径；研究员建议锁箱 ≥ 120 交易日，列为待定稿议题（见下节） |
| 成本后收益 | 净年化 > 0（含佣金、印花税、滑点、冲击），且对基准（如中证全指/沪深300）超额 > 0 | 未计成本的收益不构成可交易结论 | 研究员 |
| 跨市场状态 | 按市场状态（上行/下行/震荡/高波动）分段净收益均 ≥ 0；单一年度不亏损（首个不完整年度除外） | 只在单一行情类型下盈利的策略不具备稳定性 | 研究员 |
| 回撤与换手 | 账户级最大回撤 ≤ 20%；换手上限与资金使用率明确；成本翻倍后仍为正 | 约束「靠高换手放大收益、成本假设过乐观」 | 研究员 |
| 统计显著性 | 经多重检验校正后仍显著（BH-FDR q < 0.1 或 DSR ≥ 0.95），且 `n_trials` 如实计入；同时报告 Newey-West t | 搜索空间越大越容易找到假阳性；不做校正的显著性无意义 | 研究员（DSR/BH 原语已在 `stats_v2.py`，但未接入策略试验流程） |
| 稳健性 | 参数邻域平台而非单点最优；留一法（剔除最佳单票/最佳单年）后结论不反转；给出容量上限 | 区分真实边缘与过拟合 | 研究员 |
| 可复现 | 数据版本 + 结果指纹固定，独立复跑一致（S4） | 不可复现的收益无法验收 | 独立审核 |

判定框架的使用规则：必达项（样本外长度、成本后收益、统计显著性、可复现）任一不满足即不通过；其余为质量分级，用于比较候选而非放行。未通过锁箱的显著性结论按用户确认的降级规则处理：只作探索性记录，不进入 S5 推荐候选。若长期无候选通过，正确动作是记录负结果并收窄范围（换品种、换频率、换数据），不是下调阈值。

## 路线与门槛

G 线顺序采用 G0 证据基线 → G1 数据适用边界和现有核心故障收敛 → G2 精确策略规格/契约 → G3 研究能力集成 → G4 可交易适配和模拟复盘闭环 → G5 系统验收候选。G1、G2可并行；受限制研究允许在显著声明范围内进行，不能冒称严格历史验证。威科夫研究页不必等待所有 WFO 增强，但不得调用未通过验收的路径；其后续可交易适配必须先解除相关核心阻断。核心回测与连续 WFO 在阻断解除前，产出只能作调试数据，不得用作连续账户绩效或策略结论。

S 线顺序为 S1→S6（详见上文）。与 G 线的接口有三处硬约束：

1. S1 的评估框架可先行搭建，但其产出在被 G1-04 关闭之前只能标为调试数据；
2. S3 的批量试验必须调用经 S1 验收的同一路径，不得自建平行撮合或平行成本模型；
3. S6 的正式实现受 G4-01、G4-02 门槛约束，交易授权不在本规划范围内。

逐项交付及放行要求见 DELIVERY-CHECKLIST.md；所有未决事项见 RISKS-DEPENDENCIES.md。日期由实际门槛达成后再估，不以报告篇数、测试数量、策略数量或页面打开作为里程碑。
