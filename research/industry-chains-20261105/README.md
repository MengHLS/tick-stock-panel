# 商业航天、机器人、新能源汽车与电池产业链梳理

研究日期：2026-11-05。用途：为产业链脑图补充分类层级、节点边界和股票映射口径。本文不是投资排序；当前已按该结构落到默认图谱，运行数据仍以图谱 API 为准。

## 结论

- 三条新链都适合按“上游材料与核心部件 → 中游整机/系统 → 下游应用与服务”组织，但商业航天和机器人需要额外保留“基础共性/软件智能”这一横向层。
- 电池链可以显著细分。现有 `ne-battery` 子树只有 10 个节点，建议先扩到 50～60 个节点，再决定是否拆成独立产业链。
- 电池分类必须区分三条轴：用途（动力/储能/消费）、化学体系（磷酸铁锂/三元/钠电/固态）、产品形态（方形/圆柱/软包）。三者不是互斥的同级节点。
- 不建议现在把电池从 `power-battery` 迁出。主题分析会引用产业链 ID 和节点 ID，先保留原 ID、在原链内加深，兼容成本最低。

## 1. 商业航天

### 1.1 范围

商业航天是以企业为主体、以市场化方式提供航天产品和服务的产业，常见范围包括运载火箭、卫星制造、发射与测运控、卫星通信/遥感/导航应用，以及太空旅游、在轨服务等新兴方向。[S1][S2]

本仓库做股票研究时，建议把“商业航天”与“军工航天”分开看：很多上市公司是航天军工配套商，不能因为客户或产品涉及航天就自动归入商业航天。节点关联理由应写清具体产品，例如“提供星敏感器”“生产火箭锻件”，不要只写“商业航天概念”。

### 1.3 边界与易错点

- 火箭制造、卫星制造、发射服务、卫星运营是四个不同环节，不能用“商业航天”一个大节点全部吞掉。
- 卫星通信、卫星遥感、卫星导航是三条独立应用链，对应不同的载荷、终端和客户，不应合并成一个“卫星应用”末级节点。
- 发射场、测运控站网属于基础设施，和火箭/卫星制造分开；它们不一定有直接对应的上市公司。
- 太空旅游、在轨服务、商业空间站仍处早期，建议放在“新兴应用”下作为主题观察节点，不急于逐家映射。
- 军工配套与商业航天存在交叉。同一家公司可以同时关联两个链条，但每条关联要分别说明具体产品和业务，不能复制同一条理由。

### 1.4 代码映射建议

- 分类：`aerospace` 航空航天
- 产业链：`commercial-space` 商业航天
- 顶层节点建议：`cs-material`、`cs-electronics`、`cs-structure`、`cs-rocket`、`cs-satellite`、`cs-ground`、`cs-launch`、`cs-comm`、`cs-remote`、`cs-nav`、`cs-emerging`
- 现有节点 ID 不受影响；新增节点统一使用 `cs-` 前缀，避免和半导体、AI 链的节点混淆。

## 2. 机器人

### 2.1 范围

机器人链建议覆盖工业机器人、服务机器人、特种机器人、人形机器人和物流自动化，并把跨品类的核心零部件、软件智能单独成层。工信部机器人规划强调整机、关键零部件和系统集成协同；人形机器人指导意见则把“大脑、小脑、肢体”与整机、部组件、软件分开描述。[S3][S4]

### 2.3 边界与易错点

- 人形机器人是产品形态，不是独立于零部件之外的“第五类零部件”。它和工业机器人共用减速器、丝杠、电机、传感器，同一股票可以分别关联，分析时按股票去重。
- 关节模组是“减速器 + 电机 + 编码器 + 驱动器”的集成件，不能和单个零部件放在同一层级。
- 服务机器人和特种机器人是按场景划分；医疗机器人既可以做服务也可以做特种，入图时只选一个主归属，另一条用股票关联补充。
- 本体制造和系统集成分开。系统集成商不一定自产本体，本体厂商也不一定做终端集成。
- “具身智能”是软件与算法层，不是机器人本体；不要把大模型公司直接挂到“人形机器人整机”。

### 2.4 代码映射建议

- 分类：`advanced-manufacturing` 高端制造
- 产业链：`robotics` 机器人
- 顶层节点建议：`rb-parts`、`rb-software`、`rb-body`、`rb-integration`、`rb-upstream`
- 人形机器人建议作为 `rb-body` 下的独立产品节点，不另建一条产业链；后续如果节点过多，再拆 `humanoid-robot` 专题链。
- 与 AI 链的交叉用股票关联表达，不复制 `ai-*` 节点。

## 3. 新能源汽车

### 3.1 范围

新能源汽车链以纯电、插混/增程、燃料电池等电动化整车为主线，覆盖三电、高压补能、热管理、底盘车身、智能驾驶和智能座舱。国务院新能源汽车产业发展规划明确电动化、网联化、智能化方向，并把整车、关键零部件、基础设施和产业生态放在同一框架下。[S5]

### 3.3 边界与易错点

- 新能源汽车是电动化整车，不等于全部汽车。智能驾驶和智能座舱不是新能源车独有，如果研究范围是“汽车科技”，建议另建 `smart-vehicle` 链，不要把所有智能化公司都塞进新能源汽车。
- 电池系统节点只作为整车视角的入口，详细的材料、装备、回收放在电池链；同一股票可以两条链分别关联，不复制整棵子树。
- 纯电、插混/增程是动力形式，不能和轿车/SUV/MPV 这种车型分类混在同一层。
- 整车厂自研电池、电机、智驾时，可以同时关联整车节点和零部件节点，但理由要分别写清是“自产”“外供”还是“布局”。
- 燃料电池车属于新能源汽车，但电堆、储氢瓶、加氢站归氢能链研究，避免两边重复建节点。

### 3.4 代码映射建议

- 分类：`automotive` 汽车
- 产业链：`new-energy-vehicle` 新能源汽车
- 顶层节点建议：`nev-material`、`nev-battery-system`、`nev-drive`、`nev-hv`、`nev-thermal`、`nev-chassis`、`nev-ad`、`nev-cockpit`、`nev-vehicle`、`nev-service`、`nev-support`
- `nev-battery-system` 只放 PACK/BMS/热管理/结构件等整车视角节点；电芯、正负极、隔膜、电解液、装备、回收留在电池链。

## 4. 电池产业链细化

### 4.1 结论

可以，而且这是目前最值得细化的一条链。现有 `ne-battery` 子树只有“上游材料、正极、负极、隔膜、电解液、电芯与 PACK、动力电池、储能电池、下游应用、新能源汽车、储能系统”等少量节点，无法区分资源、主材路线、辅材、装备、形态、用途和回收。

建议保留 `power-battery` 产业链和现有 `bat-*` 节点 ID，在 `ne-battery` 下继续加深，不立即拆独立链。等节点超过 70 个、或需要单独做电池指数时，再迁移为 `battery` 链。

### 4.3 三条分类轴

| 轴 | 取值 | 放置方式 |
| --- | --- | --- |
| 用途 | 动力、储能、消费 | 放在“应用”层；同一电芯可以对应多个用途，通过股票关联表达 |
| 化学体系 | 磷酸铁锂、三元、锰酸锂、钴酸锂、钠电、固态 | 放在“正极/负极/电解液/技术专题”层，不和应用层并列 |
| 产品形态 | 方形、圆柱、软包 | 放在“电芯”层，不和化学体系混为一谈 |

固态电池、钠离子电池、4680、复合集流体、快充等是技术路线或结构创新，建议单独放在“技术专题”层。它们和材料、电芯、应用是交叉关系，不是上下游父子关系。

### 4.4 与新能源、新能源汽车的挂接

- 电池链保留在 `power-battery`（新能源产业链）内，作为“电池与材料”分支，和光伏、风电、储能系统、氢能、电网并列。
- 新能源汽车链只建“电池系统”入口，不复制正负极、隔膜、电解液等材料节点。
- 储能链只建“储能本体/系统集成”视角，不把动力电池的乘用车/商用车节点复制过去。
- 同一股票可以同时关联电池材料节点、新能源汽车电池系统节点、储能系统节点，分析时按股票去重；每条关联的理由必须不同。

## 5. 落地顺序

1. 先在 `defaults.py` 补节点，保持现有 ID 不变；只新增节点和父子关系，不改已有节点的 chain_id。
2. 在 `pool_import.py` 增加具体题材映射，例如火箭、卫星互联网、星敏感器、谐波减速器、行星滚柱丝杠、灵巧手、一体化压铸、空气悬架、线控底盘、800V、磷酸铁锂、硅碳负极、六氟磷酸锂、复合集流体、固态电解质。
3. 用现有 `read_pool_observations` 回溯近三个月涨停题材，新增关联统一标为 `pending`，保留日期、来源和原始题材。
4. 检查未匹配题材，只给“有明确产品/环节”的题材加节点；宽泛的“商业航天、机器人、新能源汽车、锂电池”不自动落到末级节点。
5. 逐条核验公司公告、官网或定期报告，再升级为 `verified`；核验前不要在页面上显示为已证实业务。
6. 运行 `validate_graph` 和相关测试，确认没有重复 ID、悬空父节点、跨链父子关系和重复股票关联。
7. 等电池节点稳定、需要独立分析时，再评估拆 `battery` 链；迁移时保留原节点 ID，并为主题分析提供兼容映射。

## 6. 命名规范

- 节点名写“产品/环节/服务”，不写公司名、股票代码、政策口号或行情题材。
- 优先使用“材料、器件、模组、系统、设备、服务”等后缀，保证同一层级的词性一致。
- 一个节点只回答一个问题：“这里制造/销售什么”。如果一句话里出现两个不同产品，拆成两个节点。
- 关联理由保持 5～20 个字符，写具体产品，例如“生产星敏感器”“提供谐波减速器”，不要写“商业航天概念”“机器人概念”。
- 上游材料和中游制造分开；同一公司既有材料又有电芯业务时，用两条关联分别表达。

## 7. 已实施结果（2026-11-05）

- 新增分类：航空航天、高端制造、汽车。
- 新增产业链：商业航天、机器人、新能源汽车。
