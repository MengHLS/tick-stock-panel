## Q1 可证伪性：**FAIL**

**先回答你点的那一处：P1 与 P5 不矛盾。**「收益略差但 OOS 略好」时 P1 判不成立、P5 也判不成立（`D_0<0` 与 `D_OOS>0` 异号），两条同向，且判定表里落「不确定·不采用」——**唯一、不冲突**。同理「T 过、OOS 差」也只掉 P5 → 灰区。这两条可以放心。

**但有四处硬缺陷，任何一处都足以让"看到结果前唯一判定"失效：**

1. **P1 的 A 门在基准上就不成立（最硬）**（v2:206-207）。
   按 v2 自己写死的口径 `A=(1+T)^(252/N_td)−1`、`N_td≈1,777`：`(1.242725)^(252/1777)−1 = 3.1296% < 3.13%`。**基准自己过不了 P1 的第二条**；反解 A 恰等于 3.13% 需要 `N_td=1776.803`，即 `N_td=1776` 时基准通过（3.1314%）、`1777` 时不通过（3.1296%）；等价地，在 `N_td=1777` 下要让 A 达标需 `T ≥ 24.2755% > T0`。
   ⇒ **一个与基准逐值相同的 run 会被 P1 判不成立。** 这不是"门太严"，是判据用了两个各自四舍五入到 2dp 的数做不等式；而 `N_td` 本身是反解值（±3–5 个交易日）。PASS 空间因此被压成空集附近——与 v1 的 P3 绝对门是同一类毛病，v2 只修了 P3 那一处，P1 这一处还在。
2. **判定表 ① 的 MDD 不等式方向反了**（v2:259 vs 212、198）。
   §2 定义 `MDD = min_t(equity_t/max−1) ∈ [−1,0]`（v2:198），P2 用 `MDD ≤ −36.27%` 表示**改善**（v2:212）；而 FAIL ① 写成"三个收益维同时劣化（`… 且 MDD > MDD₀`）"（v2:259）——负数口径下 `MDD > MDD₀` 是**回撤改善**。结果：**"三项全劣"不触发 FAIL（落灰区），"收益劣化 + 回撤改善"反被判 FAIL**。判定仍唯一，但标签与实质相反，同一文件内两处对同一量用了相反符号。
3. **`两档 PASS/FAIL 不一致` 未定义**（v2:259 ③ vs 248）。
   P4 只说"两档都必须 PASS 各自的第一层（P1∧P2）"，判定表 ③ 却说"两档 PASS/FAIL 不一致"。若 10bp 五问全 PASS、30bp 仅 P3 不成立（落灰区），这算不算"不一致 ⇒ 整体 FAIL"？无法从文本读出。
4. **P3 的排序键与计价键不是同一个量**（v2:218 vs 222）。
   排序按 `pnl_amount` 降序，但 `pnl_i` 对 end 笔取 `exit_value − entry_value`（而 `pnl_amount` 被引擎写成 0.0）。若被测臂有 end 笔进"前 5"，去尾对象与排序对象不同。**基准上恰好无害**：我复算两种排序键得到的 top-5 是同一批（`300641.SZ / 688091.SH / 688313.SH / 002455.SZ / 603322.SH`），但被测臂不保证。

**正面项（可复现，支持判据可用）**：口径自检成立——`(1.2427)^(252/1777)−1 = 3.1296%`（与 3.13% 一致到 2dp 的边界）、`(1,242,725.28/1,040,990.10)^(1/3.833)−1 = 4.7297%`、30bp `(1,134,266.20/1,000,646.57)^(1/3.833)−1 = 3.3241%`。所以 v2:202 的两条自检可以复现，问题不在口径函数，在阈值写成 2dp 常数。

## Q2 过拟合：**FAIL**

**（1）§1.1 理由 1（v2:105）判为「量级修辞」，且对池内 20% 板自相矛盾。**

  - **对 20% 板这句话直接为假**：同一份文件的标的池含创业板/科创板（v2:115 `boards` 五项），对它们 25% 只有 1.25× 跌停；**一个 20% 跌停 + 次日 −6.25% 就触线**。"单个跌停日 + 次日惯性不足以触线"在池内 20% 板上不成立。同一文件 §1.1 与 §1.2 #2 因此互相矛盾。
