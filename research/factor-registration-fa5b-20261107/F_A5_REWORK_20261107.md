### 2.1 判等域：原始键集 → `to_spec()` 语义投影

```python
def content_signature(definition: dict) -> str:
    spec = to_spec(definition)          # 缺省值由编译器/校验器补齐，依赖与预热由它推导
    projection = {
        "id": spec.id, "kind": spec.kind, "label": spec.label,
        "group": spec.group or _GROUP_DEFAULT.get(spec.kind, ""),
        "lang": spec.lang or "dsl",
        "direction": spec.direction,
        "status": str(definition.get("status", "draft")),   # stability 三态塌缩，必须单独看原值
        "stability": spec.stability,
        "warmup_bars": int(spec.warmup_bars),               # 生效值，不是书写的值
        "dependencies": sorted(spec.dependencies),          # 编译推导，不是记录值
        "formula": spec.formula_text if spec.kind == "custom" else "",
        "components": [[m, float(w)] for m, w in sorted(spec.components)],
        "description": str(definition.get("description") or ""),
    }
    return json.dumps(_canonical(projection), ensure_ascii=False, sort_keys=True, separators=(",", ":"))
```

`is_same_content` 仍是两侧签名相等；新增一条：**任一侧投影失败（非法/编译不过）返回 False**，
判等永远不会替校验放行（fail-closed）。

### 2.2 写盘：以盘上定义为底

```python
def _merge_for_write(stored, definition) -> dict:
    merged = dict(stored or {})
    for key, value in definition.items():
        if key in _NON_CONTENT_FIELDS:      # version/created_at/updated_at 由下面统一裁决
            continue
        merged[key] = value
    return merged
```

调用方显式给出的字段覆盖盘上值；**没给出的字段保留盘上值**（`lang` / `warmup_bars` / `unit` /
`scale_free` / `tags` 等）。旧实现 `updated = dict(definition)` 是「整份替换」，所以抹字段。
首次创建同理（并补上缺失的 `created_at`，与 API 建因子一致）。

## 3. 判等口径（哪些参与、哪些不参与、为什么）

| 字段 | 参与判等 | 说明 |
|---|---|---|
| `id` / `kind` | 是 | 投影主键 |
| `label` / `group` / `description` | 是 | 描述性内容；`group` 缺省按 kind 补（custom→自定义, composite→组合）；`description` 缺省按 `""` 补 |
| `formula` | 是 | 公式原文逐字符比对（改一个字符即内容变化） |
| `lang` | 是 | **缺省补 `dsl`**（`to_spec` 同一口径）→ 这是本次返工的关键修正点 |
| `direction` | 是 | 缺省补 `none` |
| `status` | 是 | 原值参与（draft/active/watch/retired 四态）；`stability` 只把它塌缩成两态，不能替代 |
| `stability` | 是 | 派生值一并进签名（冗余，但对齐注册表） |
| `warmup_bars` | 是（用生效值） | dsl 由编译推导（书写值不参与）；python 取 `max(声明值, 推导值)`，声明值因此真实参与 |
| `dependencies` | 是（用推导值） | 编译结果，不是书写值 |
| `members`（composite） | 是（用 `components` 排序后比对） | 成员键序无关；权重按 `float` 比（`1` 与 `1.0` 等价） |
| `version` / `created_at` / `updated_at` | **否** | 版本与时间戳，不代表内容 |
| `tags` / `unit` / `scale_free` / 其他附加存储字段 | **否** | `to_spec` 不消费、API 也不可写；不改变因子行为，写盘时原样保留（F1/F2 实测） |
| mtime / 文件大小 / 目录指纹 | **否** | 只看语义（F 组与判据 B/D 实测指纹只随真实内容变化） |

为什么不是白名单：投影的语义部分**由 `to_spec` 派生**——将来某个字段被它消费，就自动进入签名，
不需要有人记得来维护清单；描述性字段（description/status）在 `content_signature` 一处显式列举。
