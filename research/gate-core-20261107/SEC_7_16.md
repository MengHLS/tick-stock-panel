### 7.16 canonical/alias 闸门：可判定条款（v0.9 新增；B0b-1 的交付依据）

本节把 `FS03` 从「一句话裁定」（§7.8.4 的模式矩阵、决策文件 `ID-CANON-1`）写成**可判定条款**：触发条件、生效入口、HTTP 形状、与 §7.15 canonical 表的接续、以及拒 alias 时 `vol60` 与 `uf_vol60` 各自的期望行为。**本节不新增裁定**，只把 §7.8.2 A-2/A-3、§7.8.4、§7.15.1 已有裁定落到可测的输入输出上；判据编号续 `F-A41` 取 `F-A42`。

**7.16.2 `FS03` 触发条件（四条同时成立才触发；判据取自 §7.15.1 与 `FactorSpec`，实现不得在代码里写死 8 个名字）**

```text
alias_of(id)        := get_factor(id).alias_of          # None = 非 alias
canonical_of(id)    := alias_of(id) or id               # 传递解析，上限 4 跳（§7.8.2 A-3）
strategy_usable(id) := get_factor(id).strategy_usable   # 缺省 True；alias 恒 False
```

| 条件 | 断言 |
| --- | --- |
| C1 提交的 id 已登记 | `get_factor(submitted_id) is not None`；未登记走 `FS02`（§7.8.3），**不是** `FS03` |
| C2 `alias_of(submitted_id) is not None` | 即提交的是 alias。`FS06` 的情形（别名成环、解析目标未登记、两个 id 都自称 canonical）**先判**，`FS06` 优先于 `FS03` |
| C3 `strategy_usable(submitted_id) is False` | alias 恒 `False`；此项只作**交叉校验**——若某 alias 被错配成 `True`，仍按 C2 判 `FS03`，不因取值错而放行 |
| C4 `mode == "production"` | `research` / `diagnostic` **不**触发（§7.8.4：research 允许并标 `deprecated_alias_used`，diagnostic 允许） |

→ 触发即 **400 + `detail.code == "FS03"`**，fail-closed，不得降级为告警。§7.15.1 第 9–14 行的 6 个单侧件（`canonical_id == 研究原名`、无 alias）在任何模式都不会触发 `FS03`。

**7.16.4 HTTP 响应形状（唯一形状，`FS03` 与 `FS04`/`FS06` 共用）**

```json
{
  "detail": {
    "code": "FS03",
    "mode": "production",
    "submitted_id": "vol60",
    "resolved_id": "uf_vol60",
    "canonical_id": "uf_vol60",
    "table_row": 1,
    "message": "生产入口不允许 alias，请改用 canonical id uf_vol60"
  }
}
```

- 状态码 **400**（与 §7.8.4 / §7.7.5 一致，不新造 422、不用 409）。
- `detail` 是**对象**，不是字符串：`code` 必填；`submitted_id` / `resolved_id` 必填（§7.8.4 已要求）；`canonical_id` 与 `resolved_id` 同值（两键并存是为了与 `FS06` 的「未裁定」形状对齐）；`table_row` = §7.15.1 的行号（1–14），单侧件与未入表 id 为 `null`；`message` 为可读串。
- 批量入口（`/run-all`、`/factor/batch`）`detail.submitted_id` 取被扫描顺序的**第一条**违规，另给 `detail.violations = [{"submitted_id": …, "code": …}, …]` 列全部违规。
- `GET /api/factors` 的每个条目新增两键：`"strategy_usable": bool`、`"alias_of": str | null`（`canonical` 行 `alias_of=null`）。这是本条约定的**唯一**目录侧改动，其余键与顺序不变（`mining_schedule` 取前 48、`factor_columns_view()` 顺序均已由 §7.8.1 #11 锁死）。

**7.16.5 与 §7.15 canonical 表的接续（唯一权威，禁止二次登记）**

- alias 集合与映射**只从 §7.15.1 派生**：第 1–8 行的 `alias` 列 = 8 个 alias（`vol60`/`ma120`/`ma200`/`prior_high_20`/`prior_high_55`/`prior_high_250`/`prior_low_10`/`prior_vol_20`），`canonical_id` 列 = 8 个 `uf_*`；第 9–14 行 `alias` 为 `—`，其 `alias_of` 必须为 `None`。
- 实现侧允许的冗余只有一处：`FactorSpec.alias_of`（由 pack / store 定义写入）必须与表一致；**不一致以表为准并报 `FS06`**（表是权威、定义是投影），不得只改一边就跑通。
- 新增口径或改 alias = 改表（`ID-CANON-1`，决策文件 §3 登记）**同时**改定义；两者任一未动即 `FS06`。
- `strategy_usable` 的取值规则（唯一）：`FactorSpec` 默认 `True`（内置 77 个 base/virtual 与 6 个单侧件），**只有** `alias_of is not None` 置 `False`；不引入第三个状态，也不按 `kind` / `stability` 推导。

**7.16.6 拒 alias 时 `vol60` 与 `uf_vol60` 的各自期望行为（逐模式）**

| 提交 id | `production` | `research` | `diagnostic` | 取哪一列的数值 |
| --- | --- | --- | --- | --- |
| `uf_vol60`（canonical） | **允许**（若 `status != active` 则 `FS01`；`reference_missing` 则 `FS05`，均按 §7.8.4） | 允许 | 允许 | canonical 列（权威） |
| `vol60`（alias） | **400 `FS03`**（7.16.4 形状，`table_row=1`） | 允许，标 `deprecated_alias_used=true`、`submitted_id="vol60"`、`resolved_id="uf_vol60"` | 允许，同 research 并标 | 解析到 canonical 列（§7.8.2 A-2：alias 不各持实现） |
| 同一策略内 `vol60` + `uf_vol60` 并存 | **400 `FS04`**（`FS04` 优先于 `FS03`） | **400 `FS04`** | 允许，标 `dual_id=true` | 同上 |

- **拒 alias ≠ 数值不等**：两式实测 `max_abs_diff = 1.1102230246251565e-16`（`n_both_nonnull = 5,469,335`，非零差 **4,214,876** 行 = **77.07%**，超差 0 行；`F_CLASS_PARITY_20261107.json#factor_parity.uf_vol60`）。`FS03` 是**命名/准入**问题，不是数值问题；等价性按 **`F-A3` 的 `max_abs_diff < 1e-12`** 判，容差句挂在 **§7.15.2 硬约束①**，本节不重复定义、不改容差、不新增门槛。
- **为什么 77.07% 行不等却不算口径差**：两式运算顺序不同（`(a−b)/b` vs `a/b−1`），1 ULP 级差异在 `close` 与 `ts_delay(close,1)` 接近时绝对值为零、远离时绝对值非零但相对误差仍 ≤ 1e-16。判据看的是 `max_abs_diff` 的**绝对上界**，不是「多少行不等」。**禁止**把「77.07% 行不等」写成判据或门槛（理由同 §7.15.2：把某次实测的 ULP 当门槛，会把「同公式换个求和顺序」的正确实现判失败）。
- **可直接写成断言的四个取值**：`get_factor("vol60").strategy_usable is False`、`get_factor("uf_vol60").strategy_usable is True`、`get_factor("vol60").alias_of == "uf_vol60"`、`get_factor("ma20").alias_of is None`。
